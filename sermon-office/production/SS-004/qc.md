# QC — SS-004

> **사전 점검이다. 최종 판정이 아니다.**
> 현재 렌더의 배경은 채널 썸네일 자리표시자이고, 자막은 미교정 ASR이다.
> 정식 QC는 소스 영상과 교정된 자막으로 다시 렌더한 뒤에 돈다.

```
아이디어      SS-004
렌더          renders/final.mp4  (0:59, 1080x1920)  ← 자리표시자 배경
단계          레이아웃 검증 + 대본(클립 구간) 사전 점검
```

## 차단 사항

**1. 게이트 5 — 자막이 검증되지 않았다.** (2점, 3점 미만이므로 차단)

`captions/captions-draft.tsv`는 ASR 원문이다. 실제로 다음이 그대로 들어 있다:

| 시각 | 초안이 말한 것 | 문제 |
|---|---|---|
| 0:13 | `무시하고 이게 참 이게 참 되게에 참` | 실언·반복. 읽을 수 없다 |
| 0:28 | `아주 멸시하고 막 막 우월주의에` | 반복 |
| 0:43 | `우리가 다 이방 민족이었습니다. 예.` | 끝의 `예.`는 추임새 |

노란 자막은 **목사님이 한 말**이라고 화면에서 주장한다. 교정과 음성 대조 없이는
그 주장을 할 수 없다(헌장 하드 룰 1–2, `../../brand/shorts-format.md`).

→ **필요한 조치:** `renders/verify.mp4`를 들으면서 초안을 고치고
`--captions`로 재렌더. `captions/captions-verified.json`이 생겨야 게이트 5가
다시 채점된다.

**2. 소스 영상 없음.** 게이트 3·4·9가 채점 불가이고, 게이트 1의 절반도 확인 불가.

## 판정

```
판정          BLOCKED (사전)
차단          게이트 5 — 자막 미검증 (2/5)
              소스 영상 부재 — 게이트 3·4·9 채점 불가
반환 대상     사람 — 음성 대조 겸 자막 교정, 소스 영상 공급
다음 단계     소스 + 교정 자막 → 재렌더 → 정식 9게이트 QC
```

## 이 사전 점검이 실제로 잡은 것

**렌더가 존재한다는 사실이 게시 자격을 만들지 않는다.** SS-004는 화면상 완성처럼
보이는 59초 MP4가 있고, 레이아웃도 규격에 맞고, 비용도 0원이다. 그리고 게이트
5에서 막혔다 — 노란 글씨가 목사님의 말이라고 주장하는데 그것을 뒷받침할
증거가 없기 때문이다.

이것이 QC와 프로듀서를 분리한 이유다(헌장 §역할). 만든 쪽은 "다 됐는데 자막만
좀 다듬으면"이라고 말하고, QC는 "자막이 곧 주장 전체"라고 말한다.
