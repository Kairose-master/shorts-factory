# EXP-E07 — "명언 쇼츠" 실측 스타일 (레터박스 + 네온 외곽선 + 상시 출처)

## 배경

`../../research/christian-shorts-landscape-2026-08-31/general-viral-formats.md`
리서치에서 찾은 최적 비교군(명언/동기부여 쇼츠)의 대표 사례
"서장훈 팩폭 다 뻥입니다"(YouTube, 4,100,000회, 출처 명시:
청춘페스티벌 강연)를 실제로 다운로드해 프레임 단위로 확인했다.

**EXP-E04~E06(박스 인셋, 채널 소유자가 전부 기각)과는 다른 실험이다.**
그때는 어두운 배경 위에 영상을 작게 인셋했지만, 이 레퍼런스는 훨씬
단순하다 — 배경 장식이 없고, **원본 종횡비를 그대로 살린 레터박스**
(위아래 검정 바)일 뿐이다.

## 웹에서 "스킬"을 찾아본 결과

Remotion 기반 Claude Code 스킬 후보 세 개를 확인했다
(`AgriciDaniel/claude-shorts`, `ali-abassi/remotion-templates`,
`Bomx/super-video-maker-skill`) — 전부 Node.js/React 파이프라인이라
이 오피스의 순정 Python+FFmpeg 파이프라인과 맞지 않고, 이 정확한
스타일(레터박스+네온 외곽선+상시 출처)을 그대로 구현해 주는 것도
없었다. **새 의존성을 들이지 않고 기존 `build_short.py` 방식(ASS
자막)을 그대로 확장**해 이 실험 전용 렌더러
(`build_short_quotecard.py`)를 새로 짰다.

## 레퍼런스와 다르게 한 것 — 자세 등급 색상 규칙 보존

레퍼런스는 훅·자막 둘 다 흰색이지만, **이 오피스는 노란 자막 =
QUOTE라는 색상 규칙이 위조 방지 장치다**(`brand/shorts-format.md`
§자세 등급 — "두 색이 다른 것은 디자인이 아니라 자세 등급의 시각적
구현"). 그래서:

- 자막은 **그대로 노란색**을 유지했다.
- 자막(QUOTE)은 기존처럼 검정 외곽선의 노란 글씨.

즉 색상 구분 규칙은 그대로 두고, 구조적 요소(레터박스·상시 출처)만
가져왔다.

## 수정 — 청록 네온 외곽선 폐기 (채널 소유자 피드백)

1차 렌더는 레퍼런스의 청록 네온 외곽선을 훅에 넣었는데, 채널 소유자가
"제목 폰트가 너무구려"라고 반려했다. 원인은 폰트 자체가 아니라
외곽선이었다 — 상단 밴드에 맞추느라 훅 크기를 68pt로 줄였는데,
`build_short.py`와 같은 `Outline=7`을 그대로 쓰니 외곽선이 글자
크기 대비 훨씬 두꺼워졌고(약 10% vs 기존 6%), 거기에 밝은 청록색을
얹으니 글자 형태가 뭉개져 밈 폰트처럼 보였다. `build_short.py`가
이미 QC 통과한 검정 외곽선(비율 그대로, `Outline=4`/`Shadow=3`)으로
되돌려 재렌더했다. **네온 외곽선은 이 실험에서 폐기** — 레터박스와
상시 출처 표기만 남은 가설이다.

## 훅 문구 — 레퍼런스 그대로 베끼지 않았다

레퍼런스 훅은 "서장훈 팩폭"("팩트로 폭행" — 인터넷 밈)이었는데,
첫 렌더에서 이 표현을 그대로 흉내 내 "장선기 목사 팩폭"이라고
썼다가, 프레임을 보고 톤이 안 맞는다고 판단해 "장선기 목사 ·
새벽강해"로 고쳐 재렌더했다(L-29 — 레퍼런스는 형식만 베끼고 내용은
매번 우리 채널 기준으로 다시 판단한다).

## 이 스타일의 실질적 이점

1. **크롭 부담이 줄어든다.** 풀블리드(0.5625 비율) 대신 4:5(0.8
   비율)로 덜 공격적으로 크롭하니, 이번 소재(SS-012 소스)에서 배경
   식물·나무 스크린까지 더 여유 있게 보인다 — crop-x 재실측
   부담(L-15/L-20)이 줄어드는 부수 효과가 있다.
2. **상시 출처 표기**가 자막이 없는 구간에도 항상 떠 있어, 지금처럼
   엔드카드에서만 출처를 밝히는 것보다 저작권·출처 투명성이 더
   분명하다.
