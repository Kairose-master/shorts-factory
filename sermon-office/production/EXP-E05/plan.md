# EXP-E05 — "영화관 시청" 템플릿을 예배당 회중 실루엣으로 재해석

## 배경 — 채널 소유자 요청

"유튜브 일반 레퍼런스 중에 박스에 영상이 재생되고 그걸 영화관에서
보는것 처럼 하는 영상이 있는데, 그걸 기독교적 의미가 있는 이미지로
만들 수 있을까?"

유튜브·릴스에서 흔한 "극장에서 시청" 템플릿(어두운 관객석 실루엣 +
빛나는 스크린 박스 — 영화 리뷰·트레일러 리액션에 자주 쓰인다)을
기독교적으로 재해석했다.

## 매핑 — 극장 관객 → 예배당 회중

**지어낸 이미지가 아니다.** 많은 교회가 실제로 예배 중 설교를
대형 스크린으로 송출한다 — "회중이 스크린으로 설교를 보는" 구도는
실제 예배 풍경의 재현이지 허구의 은유가 아니다.

| 극장 템플릿 | 이 실험 |
|---|---|
| 극장 좌석 실루엣(뒷모습) | **예배당 회중 실루엣**(뒷모습, 의자 등받이 줄) |
| 무표정한 관객 | 손 든 사람 몇 명 섞음 — **찬양·기도 손짓** |
| 스크린 = 영화 | 스크린 = **설교 영상**(EXP-E04의 박스 인셋 그대로 재사용) |
| 극장의 어둠 | 암전된 예배당 — 하단 비네트로 깊이감 |

## 제작 방법

1. `EXP-E04`(박스 인셋 렌더, 채널 소유자에게 이미 전달됨)를 베이스로
   재사용 — 소재·자막·훅 동일, 변수는 실루엣 오버레이 유무 하나.
2. Pillow로 회중 실루엣 PNG(1080×1920, 투명 배경)를 절차적으로
   생성 — 의자 등받이 줄, 머리·어깨 실루엣, 손 든 사람 5명 중 1명
   비율로 섞음, 하단 비네트로 암전 효과. 스크립트:
   `make_congregation_silhouette.py`(스크래치패드, 유료 생성형 API
   미사용 — 무료 렌더 경로).
3. ffmpeg `overlay` 필터로 EXP-E04 위에 합성.

## 왜 이 방식인가 — 비용·이미지 진위

- **비용 $0.** 생성형 이미지 API를 쓰지 않았다 — 실루엣은 벡터
  드로잉이라 얼굴·인물을 지어내지 않는다(DO NOT CLAIM 5번 "성도
  개인 사연·실명" 위험과 무관 — 식별 불가능한 실루엣이다).
- **신학적으로 안전하다.** 특정 교리 주장이 없다 — 그냥 "회중이
  함께 말씀을 본다"는 장면 묘사다.
