# EXP-E06 — 실제 예심교회 본당에서 스크린으로 설교를 보는 구도

## 배경 — EXP-E05("너무 별론데")에 대한 재작업

채널 소유자가 EXP-E05(만화 실루엣 회중)를 "너무 별로"라고 평가하고
"레퍼런스 이미지 검색해봐"라고 지시했다. 웹에서 "영화관에서 보는
것처럼" 템플릿의 실제 레퍼런스를 찾아본 결과, 핵심은 **관객석에서
스크린을 바라보는 실사 사진** 위에 영상을 합성하는 것이었다
(Wikimedia Commons, CC BY-SA 4.0, 후쿠이 메트로 영화관 실내 사진으로
구도 확인).

**손으로 그린 실루엣 대신 우리 채널이 이미 갖고 있는 진짜 사진을
썼다.** SS-016 제작 때 추출했던 예심교회 본당 정지화면(TunesToTube
업로드의 소스 사진)에서 로고·워터마크를 제외하고 크롭하면, 의자들이
줄지어 스크린(강대상 뒤 어두운 패널)을 향해 있는 구도가 이미 있었다
— 외부 스톡이나 생성 이미지가 전혀 필요 없었다.

## 제작 방법

1. `sermon-office/sermons/S-20230510-EPH4/`(SS-015에서 이미 확보한
   `src-eph4b.mp4`의 정지화면)에서 실제 본당 사진을 크롭 — 흰 여백·
   로고·TunesToTube 워터마크 제외(`(105,68)-(745,662)`).
2. Pillow로 그 사진에서 **실제 스크린의 픽셀 좌표**를 육안 확인 후
   측정 — `(338,207)-(522,315)`(사진 기준 640×594). 사진을 1080폭으로
   스케일하고, 아래 여백은 사진 마지막 줄 색에서 검정으로 그라디언트
   페이드해 9:16 캔버스를 채웠다.
3. `build_short_church_cinema.py`(신규 실험 전용 렌더러)로 설교
   영상을 그 스크린 좌표에 정확히 오버레이 — 소재·자막·훅은
   `EXP-E04`·`EXP-E05`와 동일(엡5:15-20, SS-012와 같은 소재).

## 비용·이미지 진위

- **$0.** 생성형 이미지 API 미사용. 사진은 이미 확보돼 있던 우리
  채널 자신의 자산이다.
- **지어낸 장면이 아니다.** 이 교회의 실제 본당이고, 실제 그 자리에
  스크린이 있다 — "회중이 스크린으로 설교를 본다"는 연출이 아니라
  **그 교회 공간을 그대로 보여주는 것**이다.

## EXP-E04·E05와 비교

| | EXP-E04 | EXP-E05 | **EXP-E06** |
|---|---|---|---|
| 배경 | 단색 남색 | 단색 남색 + 손그림 실루엣 | **실제 예심교회 본당 사진** |
| 화면 크기 | 936×1123(큼) | 936×1123(큼) | 311×183(사진 속 실제 스크린 크기, 작음) |
| 진위성 | 중립적 배경 | 지어낸 인물 실루엣 | **우리 채널의 진짜 공간** |

**화면이 작아진 것은 트레이드오프다** — 실제 스크린 크기를 그대로
썼기 때문에 설교자 얼굴이 EXP-E04보다 작게 보인다. 이게 "우리 교회
같다"는 진정성과 "얼굴이 잘 보인다"는 가독성 사이의 선택이라, 채널
소유자 판단이 필요하다.
