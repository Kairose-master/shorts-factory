## U1 — 안 좋은 평가는 영원하지 않다 [35:10–36:19]

| | |
|---|---|
| **본문(T)** | 겔 36:1-15 취지 재진술 — 황폐했던 이스라엘 산들이 다시 경작되고 열매 맺는 땅으로 회복된다는 예언. 이 구간 자체에는 직접 봉독은 없음(6:00–6:40에서 이미 봉독) |
| **주장(C)** | "안 좋은 평가·낙인은 영원하다"는 통념은 착각이다 — 하나님 안에서 얼마든지 새롭게 바뀔 수 있다 |
| **근거(G)** | 저주받았다고 여겨지던 땅에 교회가 들어와 하나님의 뜻대로 쓰이자 오히려 잘되는 땅이 되었다는 예화. 본문의 "황폐한 땅이 회복된다"는 예언과 같은 구조 |
| **전제(W)** | 사람들은 한 번 나쁜 평가를 받으면("저주받은 땅"처럼) 그 낙인이 고정된다고 생각한다 — 설교자가 "그런 것은 사실은 존재하지 않는다"고 직접 반박 |
| **한정(Q)** | 없음 — 특정 조건 없이 "하나님 안에서" 일반적으로 적용 |
| **반론(R)** | 다루지 않음 |
| **적용(A)** | 자신이나 남에게 붙은 안 좋은 평가·낙인을 영구적인 것으로 여기지 말고, 하나님 안에서 새 사람이 될 가능성을 보라 |
| **유형** | T(본문) 1(직접 봉독 없이 취지만 재진술) · I(예화) 3(저주받은 땅 예화가 핵심 근거) |

| **독립성** | **8** — T·C 2 / 전제 3 / 자체완결 3 |

**판단 근거:** "한 번 나쁜 평가를 받으면 끝"이라는 통념은 신앙 여부와
무관하게 누구나 겪는 두려움이고("낙인 효과"), "그런 것은 사실은
존재하지 않는다"는 직접적인 반박과 "새 사람이 될 수 있다"는 희망적
결론이 40초 안에서도 완결된다. 다만 이 구간엔 직접 본문 봉독이 없고
예화(I) 중심이라 9점을 주지 않았다.

**주의 — 인접 구간(약 12:00) 사용 금지.** 같은 설교 안에 신앙생활을
무속 신앙과 대조하는 발언("조상신이 뭐라고 하나 보자")이 있다 —
타 종교/민속신앙 비판으로 읽힐 수 있어 이번 클립은 물론 향후에도
쓰지 않는다(summary.md 주의사항 2번).

이번 클립의 핵심 반박과 직접 연결되지 않아 채점하지 않는다.
