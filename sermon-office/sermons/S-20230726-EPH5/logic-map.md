## U1 — 지혜는 똑똑함이 아니라 하나님이 함께하시는 삶이다 [1:50–2:43]

| | |
|---|---|
| **본문(T)** | 엡 5:15 "그런즉 너희가 어떻게 행할지를 자세히 주의하여 지혜 없는 자같이 하지 말고 오직 지혜 있는 자같이 하여" |
| **주장(C)** | 성경이 말하는 "지혜"는 똑똑함(지능)이 아니라 하나님이 함께하시는 삶이다 |
| **근거(G)** | 본문이 "지혜 없는 자 / 지혜 있는 자"를 대구로 놓고, 설교자가 그 "지혜 있음"을 "하나님이 함께하시는 사람"으로 직접 재정의한다 |
| **전제(W)** | 청중이 통상 "지혜롭다"를 "똑똑하다·영리하다"로 이해한다는 전제 — 설교자가 이 통념을 먼저 세우고("단순히 똑똑하고 그렇지 않다는 것을 얘기하는 게 아니라") 바로 반박한다 |
| **한정(Q)** | 없음 |
| **반론(R)** | (찾지 못함) — 반론을 직접 다루지 않는다 |
| **적용(A)** | 지혜롭게 살고 싶다면 지능을 키우는 게 아니라 하나님과 동행하는 삶을 살라 |
| **유형** | T(본문) 3 · C(문맥) 1(에베소서 배경 설명 불필요, 본문 자체로 완결) |

| **독립성** | **9** — T·C 4 / 전제 3 / 자체완결 2 |

**판단 근거:** "지혜란 무엇인가"는 종교 배경과 무관하게 누구나 갖는
질문이라 문맥 설명이 거의 필요 없다. "사람들은 지혜=똑똑함이라고
생각하는데, 성경은 아니라고 한다"는 반전이 40초 안에서 완결된다 —
본문이 짧고, 반전이 명시적("단순히 똑똑하고 그렇지 않다는 게 아니라")
이라 어조 손실 위험도 낮다. SS-011(주기도문)의 U1과 같은 "짧은 본문 +
명시적 반전" 패턴.

**전제가 정말 성립하는가?** "지혜=똑똑함"이라는 세속적 통념은 설교자가
따로 논증하지 않고 청중의 상식에 기댄다. 신학적으로 논쟁적인 지점은
없다 — 지혜서·잠언 전통(여호와를 경외함이 지혜의 근본)과도 일치하는
표준적 해석이라 안전하다.

## U2 — 세월(시간)은 크로노스가 아니라 카이로스다 [2:43–]

| | |
|---|---|
| **독립성** | **6** — T·C 2 / 전제 2 / 자체완결 2 |

크로노스/카이로스 구분은 헬라어 설명이 끼어들어(원어 개념 자체를
설명해야 함) 문맥 부담이 U1보다 크다. "세월을 하나님의 시간으로
만들라"는 제목 자체의 핵심이지만, U1과 이어붙이면 두 반전이 겹쳐
길어진다. 별도 소재 후보로 남겨둔다 — 지금은 채점만 해두고 제작하지
않는다.
