# 논리 재분석 — S-20260225-MAT6

본문: 마태복음 6:9-15 (주기도문) · 설교자: 장선기 목사

이 문서는 내부용이다. 게시되지 않는다. 목적은 비평이 아니라 선별 —
"이 논증이 40분의 문맥 없이 60초 안에서 혼자 설 수 있는가."

## U1 — 일용할 양식은 기도의 목적이 아니라 수단이다 [2:00–2:23, 6:58–7:46]

| | |
|---|---|
| **본문(T)** | 마 6:9 "하늘에 계신 우리 아버지여, 이름이 거룩히 여김을 받으시오며" · 6:10 "나라가 임하시오며 뜻이 하늘에서 이루어진 것 같이 땅에서도 이루어지이다" · 6:11 "오늘 우리에게 일용할 양식을 주시옵고" |
| **주장(C)** | "일용할 양식"(경제적 필요)은 기도의 첫머리도 목적도 아니다 — 기도의 중간에, 하나님의 이름·나라·뜻 다음에 나오는 **수단**이다 |
| **근거(G)** | 주기도문 9-11절의 실제 순서: 하나님 아버지 → 이름이 거룩히 → 나라가 임하시며 뜻이 이루어지이다 → (그다음에) 일용할 양식. 순서 자체가 텍스트에 있다 |
| **전제(W)** | 기도에서 무엇을 먼저 구하는지가 그 사람(또는 그 기도)의 우선순위를 드러낸다 — "하나님 없이 사는 사람은 돈 문제에서부터 시작한다"는 관찰과 대구를 이룬다 |
| **한정(Q)** | 없음 — 본문 순서 자체를 근거로 삼는 구조라 예외 조건이 붙지 않는다 |
| **반론(R)** | (찾지 못함) — 설교자가 반론을 직접 다루지 않는다. 이 주장에 대한 통상적 반론("그래도 실제로 먹고사는 문제가 급하지 않냐")은 본문 밖의 논쟁이라 이 클립 범위 밖 |
| **적용(A)** | 돈·소유를 삶의 목적으로 삼지 말고, 하나님의 뜻이 이루어지는 수단으로 재배치하라 |
| **유형** | T(본문) 4 · C(문맥) 1(주기도문은 별도 설명 없이도 누구나 안다) |

| **독립성** | **9** — T·C 4 / 전제 3 / 자체완결 2 |

**판단 근거:** 주기도문은 비신자도 아는 텍스트라 배경 설명이 거의
필요 없다(문맥 부담 최소). "사람들은 돈부터 생각하는데, 기도는 그걸
가운데 두고 수단으로 다룬다"는 반전이 30초 안에 완결된다. 경제적
불안이라는 보편적 감정에서 출발해 성경 순서라는 객관적 근거로 착지하는
구조가 SS-009(2SA5)·SS-010(1CO13)의 U1과 같은 패턴이다.

**전제가 정말 성립하는가?** "기도의 순서가 우선순위를 드러낸다"는
전제는 설교자가 명시적으로 논증하지 않고 청중의 상식적 동의에 기댄다
(반문형 화법: "돈 문제에서부터 시작해요, 그죠?"). 신학적으로 논쟁적인
전제는 아니다 — 오히려 매우 통상적인 기독교 해석이다.

## U1을 클립으로 만들 때 — 점프컷 필요 (L-17 적용)

핵심 A(2:00–2:23, ~22초)와 핵심 B(6:58–7:46, ~48초) 사이 약 4분 35초는
9-10절을 절 단위로 풀어 설명하는 확장부다("하늘에 계신 우리 아버지"로
시작하면 문제가 작아진다는 심리적 효과, "이름이 거룩히"·"나라가 임하시며"
해설, 3:44 부자 친척 비유). **이 구간을 빼도 핵심 주장(양식은 목적이
아니라 수단, 기도의 가운데 위치)은 바뀌지 않는다** — 오히려 반복·부연이라
빼는 쪽이 30초 룰에 맞다.

- **순서 보존**: A(2:00)가 B(6:58)보다 먼저 — 원래 순서 그대로.
- **결론 불변 확인**: 빠지는 구간은 같은 주장의 반복·확장이지 새로운
  전제나 반론이 아니다. A만 들으면 "왜 가운데 있는지"에 대한 문제 제기,
  B만 들으면 "그래서 무슨 뜻인지"에 대한 답 — 둘을 이으면 완결된다.
- **편집점 표기**: 훅·자막·QC 문서에 점프컷임을 명시한다.

## U2 — "하늘에 계신 우리 아버지"를 부르면 문제가 작아진다 [2:23–4:20]

| | |
|---|---|
| **독립성** | **6** — T·C 2 / 전제 2 / 자체완결 2 |

심리적 위안 효과에 대한 설명(고난·문제의 "비중이 줄어든다")과 부자
친척 비유(3:44)가 딸려 있어 U1보다 문맥 설명이 더 필요하다. 위안을
주는 내용이지만 "일용할 양식"이라는 이 설교의 핵심 반전과는 결이 다른
보조 논증이라 U1과 합치면 길어진다. 별도 소재 후보로 남겨둔다 —
지금은 채점만 해두고 제작하지 않는다.

## U3 — 하나님이 다스리시면 불행이 없어진다 [6:04–6:41]

| | |
|---|---|
| **독립성** | **5** — T·C 2 / 전제 1 / 자체완결 2 |

"땅이 불행한 이유는 세상 나라의 시스템 때문"이라는 구절은 사회 비판으로
읽힐 여지가 있고("잘못된 시스템"), 이어지는 논증이 반문형 수사("좋아질까요
안 좋아질까요?")에 의존해 본문 없이는 설득력이 약하다. 독립성 7 미만 —
쇼츠 후보 아님.
