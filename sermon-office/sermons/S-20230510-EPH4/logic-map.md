## U1 — 교회는 건물이 아니라 성도의 연합이다 [47:55–48:25]

| | |
|---|---|
| **본문(T)** | 엡 4:16 취지("그에게서 온 몸이 각 마디를 통해 도움을 받음으로 연결되고 결합되어... 사랑 안에서 스스로 세운다")를 설교자가 자기 말로 재진술 — 이 클립 구간에는 봉독 자체는 없음 |
| **주장(C)** | "성경을 모르니까" 건물을 크고 화려하게 짓는 것을 교회의 영광으로 착각한다 — 진짜 교회는 성도들이 그리스도를 닮아가며 서로 연결되어 그리스도의 몸을 충만하게 세우는 것이다 |
| **근거(G)** | 엡 4:7-16 전체가 "그리스도의 몸을 세우려 하심"을 은사·직분의 목적으로 제시한다 — 몸의 비유는 건물이 아니라 유기체(살아있는 연합)다 |
| **전제(W)** | "교회를 크고 웅장하게 짓는 것 = 하나님의 영광"이라는 통념이 널리 퍼져 있다 — 설교자가 이를 "성경을 모르니까"라고 규정하고 "아니에요"로 직접 반박한다 |
| **한정(Q)** | 없음 — 건물 자체를 부정하는 것이 아니라 "건물=교회"라는 등식을 부정 |
| **반론(R)** | 다루지 않음 |
| **적용(A)** | 교회의 성장을 건물 규모가 아니라 성도 간의 연결과 서로 닮아감으로 측정하라 |
| **유형** | T(본문) 1(직접 봉독 없이 취지만 재진술) · C(문맥) 3(통념→반박 구조가 이 구간 안에서 완결) |

| **독립성** | **8** — T·C 2 / 전제 3 / 자체완결 3 |

**판단 근거:** "교회=건물"이라는 통념은 교회에 다녀본 적 없는 사람도
직관적으로 이해하는 흔한 오해이고, "아니에요"라는 명시적 반박이
구간 안에서 즉시 나온다 — 40초 안에서도 통념→반박→대안 제시 구조가
완결된다. 본문 봉독이 이 구간 안에 없어(엡 4:7-16은 앞부분에서
이미 다룸) 9점을 주지 않고 8점으로 매겼다.

**클립으로 만들 때 — 구간 시작점을 늦춘다.** "이것이 바로
교회입니다"(47:36)로 시작하면 더 강한 도입이 되지만, 바로 이어지는
47:39–47:55 구간의 ASR이 조각나 있고("막 그 중세시대 보면... 교회당
늦게 올리고 다 거짓말쟁이들이잖아요") 무엇을 가리키는지 확신할 수
없다 — 정확한 워딩을 확인할 수 없는 구간은 쓰지 않는다는 원칙에
따라 통째로 제외하고, 47:55("성경을 모르니까...")부터 시작한다.
그래도 통념→반박 구조가 스스로 서므로 독립성에 손실이 없다.
