## U1 — 나이 들면 안 바뀐다는 건 거짓말이다 [41:43–42:08]

| | |
|---|---|
| **본문(T)** | 시 119편 전체의 권면(말씀을 평생 붙들라)의 적용 — 특정 절 재인용은 아니고, 시편 전체가 요구하는 "평생 방향을 바꿔 나가라"는 태도의 직접 적용 |
| **주장(C)** | "나이가 들면 성격·습관이 안 바뀐다"는 흔한 생각은 거짓말이다 — 안 바뀌는 진짜 이유는 나이가 아니라 말씀(기준) 없이 자기 생각대로 살기 때문이다 |
| **근거(G)** | 설교자 자신의 관찰 진술: "말씀 없이 가니까 안 바뀌는 거", "자기 생각으로 가니까" — 뒤이어 신앙 연차가 쌓인 성도(권사·장로)의 온유함을 실례로 든다(구간 밖, 42:14-42:27) |
| **전제(W)** | 사람들은 나이·연차가 변화 불가능성의 원인이라고 여긴다 — 설교자가 이 통념을 질문형으로 먼저 제시("바뀌겠어요? 안 바뀌겠어요?")한 뒤 "그건 거짓말"이라고 직접 반박 |
| **한정(Q)** | 없음 — "말씀 안에서 겸손하게 계속 연습하면" 이라는 조건은 있지만 예외 상황은 다루지 않음 |
| **반론(R)** | 다루지 않음 |
| **적용(A)** | 나이·신앙 연차를 변화 못하는 핑계로 삼지 말고, 말씀을 기준 삼아 자신의 생각·감정을 계속 다듬어야 한다 |
| **유형** | C(문맥) 3(통념 제시→직접 반박 구조가 이 구간 안에서 완결) · A(적용확장) 2 |

| **독립성** | **8** — 통념·반박 모두 구간 안에서 완결 3 / 전제 명시적 2 / 자체완결 3 |

**판단 근거:** "나이 들면 사람은 안 바뀐다"는 통념은 신앙과 무관하게
누구나 아는 말이라 진입 장벽이 매우 낮고, 반박("그건 거짓말이다 →
진짜 원인은 나이가 아니라 기준 없이 사는 것")이 짧고 명확하다.
SS-016(겔36)만큼 본문을 직접 재인용하지는 않아(시 119편 특정 절
인용이 아니라 시편 전체 권면의 적용) 10점을 주지 않는다 — 근거가
설교자의 관찰 진술이지 본문 직접 인용이 아니라는 점에서 T가 아니라
C·A 유형으로 분류했다.

**클립으로 만들 때 — 시작점.** "이것을 꼭 놓치지 마시고 평생...
방향성을 계속 바꿔 나가십시오"(41:31)부터 시작하면 "무엇을 놓치지
말라는 건지"가 앞 문맥 없이는 불분명하다. "평생 바꿔 나가.
바뀌겠어요? 안 바뀌겠어요?"(41:43)부터 시작하는 것이 통념 질문으로
곧장 들어가 더 깔끔하다.

## 보조 후보 — U2 [26:15–26:35, 채점만, 이번엔 미채택]

"저를 누가 존중할까요? 칭찬하는 사람이 저를 존중할까요? 아니에요"
— 존중은 칭찬이 아니라 말을 귀담아 듣고 그대로 행하는 것이라는
비유, 말씀 순종에 적용. 독립성 추정 6-7(비유는 강하지만 "말씀을
지키는 것=하나님을 존중하는 것"이라는 결론까지 가려면 앞뒤 문맥이
더 필요) — 이번 제작에서는 U1이 더 짧고 완결도가 높아 채택하지
않았다. 다음 소재가 부족할 때 재검토.
