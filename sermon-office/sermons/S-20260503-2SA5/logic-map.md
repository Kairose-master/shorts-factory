## U1 [49:42 – 52:36] "나도 겪어봤어"는 대개 틀린 말이다

| | |
|---|---|
| 본문 | 삼하 5:22-23 (두 번째 침공, 같은 장소·다른 전략) |
| 주장 | 겉보기에 같은 상황도 변수가 다르며, 누구의 인생도 "처음 가는 길"이다. 손쉬운 "나도 겪어봤다"는 위로가 아니라 오만이며, 진짜 태도는 겸손한 위로 + 하나님을 함께 의지하도록 축복하는 것이다 |
| 근거 | `T` 22-23절(같은 골짜기, 다른 전략 — "올라가지 말고 뒤로 돌아서 기습하라") · `C` 변수의 다양성(경제학적 배경, 하버드 교수 대 원숭이 다트 예화) |
| 전제 | **(비교적 명시적)** "겉보기에 같은 상황도 내부 변수가 다르다"는 전제가 결론과 거의 동치 — 이례적으로 전제 은폐가 적은 단위 |
| 한정 | 있음 — "100% 똑같은 상황"이라는 표현으로 정도의 차이를 인정 |
| 반론 | **다룸** — "지난번에 이겼으니 이번에도 똑같이 하면 된다"는 통념을 먼저 세우고("과거의 경험이 있으니까") 정면으로 반박한다 |
| 적용 | 두 갈래: (가) 손쉬운 조언 대신 겸손한 위로 (나) 회중과 함께 실제로 축복 기도를 드림 |
| **독립성** | **9** — T·C 4 / 전제 3 / 자체완결 2 |
| 각도 | 반전축 → 기둥 B("나도 겪어봤어"의 통념을 뒤집음) · 적용축 → 기둥 C(위로·축복이라는 구체 행동) |

**다윗 이야기의 배경지식이 거의 필요 없다.** "같은 적이 두 번째로 쳐들어왔는데
하나님이 다른 전략을 주셨다"는 한 문장이면 T·C가 성립하고, 나머지는
보편적인 인간 경험(위로랍시고 하는 말이 오히려 상처가 되는 것)으로 전개된다.
전제가 결론과 거의 같은 문장이라는 점이 오히려 독립성을 높인다 — 청중이
따로 유추할 것이 적다.

**회중과 함께하는 축복 기도(52:09–52:33)는 실제 예배의 한 순간이다.**
"당신이 걷고 있는 길은 처음 가는 길입니다… 하나님을 의지하면서 이겨
나가시기를 축복합니다"라는 콜앤리스폰스는 편집으로 만든 것이 아니라
그 예배에서 실제로 일어난 일이며, 그 자체로 쇼츠의 클라이맥스가 된다.
