## U1 [49:19 – 51:36] 테바 — 방향키 없는 인생

| | |
|---|---|
| 본문 | 창 12:1-9 도입부 (직접 인용 아님, 설교자의 서론) |
| 주장 | 인간은 인생의 방향키를 스스로 쥐고 있다고 착각하지만, 실은 방향키 없는 배(테바)를 탄 존재다. 하나님이 인도하지 않으면 길을 알 수 없다 |
| 근거 | `T` 창세기 6장 노아의 방주(테바) · `T` 출애굽기 2장 모세의 갈대상자(테바) · `C` 히브리어 "테바"의 뜻(방향키 없는 배) |
| 전제 | **(명시 안 됨)** 인간은 스스로 인생을 계획할 능력이 근본적으로 제한되어 있다 |
| 한정 | 없음 — 전면적 주장("모든 사람들에게 주님께서 선포하고 계시는 것") |
| 반론 | 다루지 않음. 다만 "너희 착각하지 마"라는 표현으로 통념(내가 방향키를 쥐고 있다)을 직접 반박한다 |
| 적용 | 인생을 계획대로 통제할 수 있다는 생각을 내려놓는다 |

| 각도 | 본문축 → 기둥 D(성경 배경 — "테바"라는 단어의 성경적 용례) · 반전축 → 기둥 B |

**노아의 방주와 모세의 갈대상자는 청중이 이미 아는 이야기다.** 배경 설명이
거의 필요 없어 자체완결성이 높다. "테바"라는 단어 하나가 두 이야기를 묶는
것이 이 단위의 발견이며, 60초 안에서도 그 발견이 그대로 전달된다.

**전제가 명시되지 않았지만** — "인간이 스스로를 통제할 수 없다"는 것이
바로 결론이므로, 전제와 결론이 사실상 같은 문장의 두 표현이다. 그래서
전제 점수를 만점(3)이 아니라 2로 매긴다: 전제가 숨은 게 아니라 결론과
겹친다는 뜻이고, 이것은 순환이 아니라 정의에 가깝다.
