## U1 — 육체적 행동은 영적인 것과 분리되지 않는다 [6:47–6:59, 8:13–9:21]

| | |
|---|---|
| **본문(T)** | 엡 4:26-27 "분을 내어도 죄를 짓지 말며 해가 지도록 분을 품지 말고 마귀에게 틈을 주지 말라" |
| **주장(C)** | "화내는 것쯤이야 영혼과 상관없겠지"라는 생각은 착각이다 — 육체적 행동(분노)은 영적 상태와 직결되고, 그 영향은 심리(우울·불면)에까지 이어진다 |

| **전제(W)** | 사람들은 통상 "육적인 것"(감정·행동)과 "영적인 것"(신앙 상태)을 별개로 여긴다 — 설교자가 이를 "착각"으로 먼저 규정하고 반박한다 |

| **독립성** | **8** — T·C 3 / 전제 3 / 자체완결 2 |

**판단 근거:** 분노·우울·불면은 종교와 무관하게 누구나 겪는 경험이라
공감대가 넓다. "행동과 신앙은 별개"라는 통념을 "착각하지 마세요"로
직접 반박하는 구조가 명확해 40초 안에서도 설득력이 유지된다. 다만
"마귀에게 틈을 준다"는 표현이 초자연적 언어라 완전 비신자에게는
SS-011·SS-012보다 약간의 해석이 더 필요할 수 있어 독립성을 9가 아닌
8로 매겼다.

**클립으로 만들 때 — 점프컷 필요 (L-17 적용).** 본문 봉독(6:47–6:59)과
핵심 적용(8:13–9:21) 사이(약 1분 14초)는 메시지 성경 번역본 인용과
의사·엑스레이 비유로, 같은 요지("겉으로 드러난 것은 속과 연결돼
있다")의 반복·예화다. 순서는 그대로(봉독 → 적용), 결론은 바뀌지
않는다.
