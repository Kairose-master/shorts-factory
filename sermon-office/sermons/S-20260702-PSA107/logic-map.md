## U1 — 하나님은 늘 도와주시기만 하는 분이 아니다 [25:52–27:00]

| | |
|---|---|
| **본문(T)** | 시 107:33-34 "여호와께서는 강이 변하여 광야가 되게 하시며 샘으로 마른 땅이 되게 하시며 그 주민의 악으로 말미암아 옥토로 염전이 되게 하시며" — 설교자가 직접 재인용 |
| **주장(C)** | 하나님은 늘 건지고 도와주는 쪽으로만 일하시는 분이 아니다 — 교만한 자를 낮추고, 낮은 자를 높이시는 반전도 하나님이 하시는 일이다 |
| **근거(G)** | 본문이 "강이 광야가 되고, 옥토가 염전이 된다"는 정반대 방향의 사례를 직접 제시한다 |
| **전제(W)** | 사람들은 "하나님은 늘 좋은 쪽으로, 구해 주고 도와주는 쪽으로만 일하신다"고 단순하게 생각한다 — 설교자가 "이건 거꾸로죠"라고 직접 규정하며 반박 |
| **한정(Q)** | 있음 — "주민의 악으로 말미암아"라는 조건이 있다. 무작정 반전이 아니라 이유가 있다 |
| **반론(R)** | 다루지 않음 |
| **적용(A)** | 좋은 상황이 항상 좋은 신호가 아니고, 어려운 상황이 항상 나쁜 신호가 아니다 — 하나님의 낮추고 높이시는 계획을 보라 |
| **유형** | T(본문) 3(직접 재인용) · C(문맥) 1(반전 규정 자체는 이 구간 안에서 완결) |

| **독립성** | **8** — T·C 3 / 전제 3 / 자체완결 2 |

**판단 근거:** "하나님은 늘 도와주기만 한다"는 단순화된 신앙 이미지를
본문으로 직접 반박하는 구조는 강하다. 다만 "주민의 악으로 말미암아"
라는 표현이 "고난 = 죄의 벌"로 오독될 여지가 있어(캡션에서 일반
원리로만 다뤄야 함) 9점을 주지 않았다.

**주의 — 오독 위험.** 이 표현을 특정 개인·집단에 대한 심판적 언어로
승격시키면 위험하다(헌장 §DO NOT CLAIM 4·6 인접 영역은 아니지만
같은 결의 위험). 설교자 본인의 적용도 "교만한 자는 낮추고 어려운
자는 높이신다"는 일반 원리로 마무리한다 — 캡션·훅도 이 프레임을
유지하고, "네가 힘들면 죄 때문"이라는 식으로 들리지 않게 한다.

## 예약 — U2 성공은 내 능력 때문이 아니다 [36:29–38:15]

2002년 월드컵 히딩크 감독 사례로 "무언가 잘되면 내 능력 때문이라고
착각하지만, 그렇게 되는 경우는 없다"고 말하는 예화. SS-016(겔36,
"내가 잘해서 받은 걸까요")과 같은 결의 논증이라 이번 라운드에서는
쓰지 않고 예약해 둔다 — 이후 시간이 지나 재사용하거나, SS-016과
비교하는 콘텐츠(같은 주제, 다른 설교의 다른 예화)로 쓸 수 있다.
