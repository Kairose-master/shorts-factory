# 콘텐츠 백로그

**생성 2026-08-29.** 이 백로그는 브레인스토밍의 산출물이 아니다.

```
설교 → 논증 단위 → 독립성 점수 → 각도 → 백로그 한 행
```

모든 행은 `sermons/<설교>/logic-map.md`의 한 단위에서 나온다. 근거가 되는
단위 없이 생긴 행은 검증기가 잡는다.

## 자세 등급 — 화면 표현을 결정하는 필드

| 등급 | 화면에 허용되는 것 |
|---|---|
| **QUOTE** | 목사님 발화로 표기 가능. **음성 대조 완료 필수** |
| **RECONSTRUCTED** | 나레이션 가능. 따옴표 금지, 목사님 발화로 표기 금지 |
| **EDITORIAL** | 명백히 제작자의 목소리여야 함 |

**EDITORIAL을 QUOTE처럼 보이게 하면 위조다**(헌장 §자세 등급).

## 점수

```
우선순위 = 훅(H)×3 + 독립성(I)×2 + 명료성(U)×2 + 시각(V) + 신선함(N) − 난이도(D)×2
```

각 0–10. **난이도는 제작 비용이므로 높을수록 나쁘다.** 최대 90.

- **독립성(I)** 은 자유 점수가 아니다. 논리 지도가 그 단위에 매긴 값을 그대로
  옮긴다. 검증기가 두 문서를 대조한다.
- **명료성(U)** 은 교회에 다녀본 적 없는 사람 기준이다.
- `Pri` 칸은 스크립트가 검산한다. 손으로 고치지 않는다.

(`../brand/shorts-format.md`). 남은 것은 사람만 할 수 있는 두 가지다:

1. ~~소스 영상~~ — **해결됨.** Apify 로 원본을 받았다($0.71, L-11). 다만 새벽기도
   업로드에는 **화면이 없다** — 정지 사진 + 음성이다(L-10). 렌더는 **본인 음성**을 쓴다

둘 다 끝나기 전에는 QUOTE가 아니다. 검증기가 `captions-verified.json` 의
유무로 확인한다.
