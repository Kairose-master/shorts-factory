## 세 층, 그리고 색이 뜻하는 것

```
┌─────────────────────────────┐  ← 0%
│                             │
│   먼저 믿은 게              │  8.1–21%   흰색 · EDITORIAL
│   우월이 되는 순간          │            (오피스가 쓴 말)
│                             │
│      [ 설교 영상 ]          │  풀블리드 9:16
│                             │
│                             │
│   우리가 다 이방            │  ~72–78%   노란색 · QUOTE
│   민족이었습니다            │            (목사님이 한 말)
│                             │
│   ▓▓ 유튜브 UI ▓▓           │  81.7% 이하 — 침범 금지
└─────────────────────────────┘  ← 100%
```

**두 색이 다른 것은 디자인 선택이 아니라 자세 등급의 시각적 구현이다.**

- **흰색 = 오피스의 목소리.** 훅, 질문, 전환. 목사님이 하지 않은 말.
- **노란색 = 목사님의 목소리.** 실제 발화. 음성 대조를 통과한 것만.

흰 글씨에 목사님이 한 말을 넣거나, 노란 글씨에 오피스가 지어낸 말을 넣으면
**등급 위조**다. 헌장 §자세 등급, QC 게이트 5. 자동 REJECT.

## 자막 교정 루프 — 이 포맷에서 가장 중요한 공정

ASR 자막을 그대로 노란 글씨에 올리면 안 된다. 두 가지 이유가 있고 둘 다 실측이다.

1. **읽을 수 없다.** 실제 설교의 ASR에는 실언과 반복이 그대로 남는다 —
   `이게 참 이게 참 되게에 참`, `막 막 우월주의에`.
2. **틀린다.** 교회 어휘에서 체계적으로 오인식한다
   (`../research/channel-model.md` §5).

그래서 렌더러는 자막을 두 단계로 만든다:

```
1. 초안        build_short.py           → renders/captions-draft.tsv
                                          (ASR 원문, 등급 RECONSTRUCTED)
2. 대조 클립    build_short.py --verify  → renders/verify.mp4
                                          (훅 없이 자막 + 타임코드만)
3. 사람         verify.mp4 를 들으며 draft.tsv 를 고친다
                ← 이 행위가 곧 음성 대조다. 두 일을 따로 하지 않는다
4. 본편        build_short.py --captions <고친파일>
                                        → renders/final.mp4  (등급 QUOTE)
                                        → renders/captions-verified.json
```

**`captions-verified.json` 이 없는 렌더는 QUOTE가 아니다.** 노란 자막이 있어도
아직 목사님의 말이라고 화면에 주장할 수 없다. 검증기가 이것을 확인한다.

교정할 때의 원칙:
- **말한 것만 적는다.** 실언·반복은 지우되, 말하지 않은 것을 넣지 않는다.
- 지울 자막은 행 전체를 지운다. 텍스트만 비우지 않는다.
- 문장을 매끄럽게 만들려고 어미를 바꾸지 않는다. 그건 RECONSTRUCTED다.

## 기둥 E 는 둘로 나뉜다 — 소스에 화면이 있느냐

`../research/channel-model.md` §9 · 교훈 L-10.

| | 소스 | 화면 | 자세 |
|---|---|---|---|
| **E-촬영** | 주일·수요·특별예배 촬영본 | 실제 영상 9:16 크롭 | QUOTE |
| **E-음성** | 새벽기도 (TunesToTube 음성 업로드) | 채널 자체 사진 + 명암막 | QUOTE |

**둘 다 QUOTE 다.** 목소리가 본인이면 인용이 성립한다. 다른 것은 화면뿐이고,
그것은 QC 게이트 4(시각 품질)에서 감점될 뿐 게이트 5(본문 충실성)와는 무관하다.

E-음성에 쓰는 옵션:

```bash
--still <채널 사진>          # 화면
--audio-from <원본 mp4>      # 소리는 설교 원본에서
--crop-x 0.28                # 9:16 크롭 위치 (0 왼쪽 · 0.5 가운데)
--scrim 0.42                 # 글자 가독성을 위한 검은 명암막
--speed 1.15                 # 설교 특유의 늘어짐을 걷어낸다. 음높이 유지
```

**합성 음성이 아니므로 AI 고지를 붙이지 않는다.** 붙이면 거짓이다.

### 배속

`--speed` 는 `setpts` 와 `atempo` 를 함께 건다. 음높이는 유지된다.
1.15–1.45 가 실용 범위. 설교는 원래 느리게 전달되므로 1.15 만으로도 체감이 크다.
**논증을 깨뜨리면서까지 배속으로 길이를 맞추지 않는다.**

### 음량

`loudnorm=I=-14` 이 기본이다. 설교 녹음은 대개 조용해서(실측 평균 −27 dB)
그대로 올리면 쇼츠 피드의 다른 영상보다 작게 들린다. `--no-loudnorm` 으로 끈다.

### 소스 사전 크롭

교회 업로드에는 흰 여백과 워터마크 띠가 붙는 경우가 많다.
`--source-crop W:H:X:Y` 로 9:16 채우기 **전에** 실제 화면 영역만 남긴다.

## 기둥 A·B·C·D·F — 나레이션 포맷

소스 영상이 필요 없는 포맷. 구현은 `../production/_engine/build_narration.py`.
기둥 E 와 색 문법을 공유하고, 세로 배치만 다르다.

```
 155–400    흰색 훅 2줄 (전체 길이 고정)        HOOK
   ~900     본문 문장 1개, 문장마다 교체         BODY
  ~1250     성경 장·절 참조                     CITE
  ~1400     출처 · 관계까지 명시                 ATTR
  ~1452     합성 음성 고지                       DISC
  ~1500     진행바 (흰색 50%)                    drawbox
  1568~     유튜브 UI — 침범 금지
```

| 속성 | 값 |
|---|---|
| 배경 | `gradients` 3색 남색 그라디언트 · `r=30` · 아주 느린 확대 |
| 본문 | 76px · 한 줄 15자 · 최대 4줄 · 화면 중앙 배치 |
| 나레이션 | Piper `ko_KR-kss-medium` · `--length-scale 0.88` |
| 진행바 | **흰색.** 노란색은 QUOTE 전용이므로 장식에 쓰지 않는다 |

**`gradients` 는 기본 25fps 다.** `r=30` 을 주지 않으면 `zoompan=fps=30` 이
프레임 수를 유지한 채 재타이밍해 영상이 짧아지고 `-shortest` 가 오디오를 자른다.

### 귀속은 관계까지 말한다 — 교훈 L-09

하단 출처에 설교자 이름만 적으면, 합성 음성이 말하는 화면에서 시청자는 그
목소리를 그 사람의 것으로 읽는다. 반드시 두 줄로 쓴다:

```
장선기 목사 설교 「겔 47:13-23」 2026-08-28 에서 재구성
나레이션은 AI 합성 음성입니다 · 방배동 예심교회
```

`--disclosure` 기본값에 박혀 있다. 비우려면 명시적으로 빈 문자열을 넘겨야 하고,
그렇게 할 이유는 목사님 실제 음성을 쓰는 경우뿐이다.

### RECONSTRUCTED 가 왜 흰색인가

노란색은 **음성 대조를 통과한 실제 발화**에만 쓴다. RECONSTRUCTED 는 설교자의
논증을 오피스가 자기 말로 옮긴 것이므로 화면에서 말하는 주체는 오피스다.
그래서 EDITORIAL 과 같은 흰색이다.

렌더러는 대본에 QUOTE 줄이 있는데 `captions/captions-verified.json` 이 없으면
**렌더를 거부한다.**

## 엔드카드 — 모든 쇼츠의 마지막 3.5초

제작 SOP 13단계: **CTA 는 항상 전편 설교로 보낸다.** 쇼츠가 설교를 대체한다고
말하지 않는다(DO NOT CLAIM 8). 두 렌더러 모두 기본으로 붙인다(`--endcard 3.5`).

```
원본 설교 전체는 채널에 있습니다        50px · 흐리게
2026년 8월 28일 새벽기도                76px · 굵게 · 흰색
겔 47:13-23 · 장선기 목사               50px
방배동 예심교회                          50px
```

**내용은 `sermons/<id>/meta.json` 에서 만든다. 손으로 적지 않는다.** 날짜·예배
종류·본문·설교자가 자동으로 들어가므로, 다른 설교의 카드를 붙이는 실수가 나지
않는다.

구현: 마지막 프레임을 `tpad=stop_mode=clone` 으로 물리고 그 구간을 `black@0.45–0.55`
로 덮은 뒤 글자를 얹는다. 오디오는 `apad` 로 무음을 채운다.
`--endcard 0` 으로 끈다.

**ASS 알파는 `&HAA…` 에서 `00` 이 불투명, `FF` 가 완전 투명이다.** 흐린 보조
텍스트를 만들려고 `&HC0` 을 쓰면 거의 안 보인다. `&H18`–`&H30` 이 실용 범위다.

## 넣지 않는 것

- **인트로·로고 선행.** 교회 로고는 엔드카드에만.
- **효과음·급발진 편집.** 이 채널의 톤이 아니다(QC 게이트 8).
- **자동 자막 원문 그대로의 노란 글씨.** 위의 교정 루프를 거치지 않은 것.
- **성경 구절을 따옴표로.** 개역개정 원문 대조 전에는 인용문으로 띄우지 않는다.
- **합성 인물, AI 생성 얼굴.**

## 실행

```bash
E=sermon-office/production/_engine/build_short.py

# 1. 초안 + 레이아웃 확인 (소스 영상 없으면 --still 로 정지화면)
python3 $E --sermon S-20260828-EZK47 --shorts-id SS-004 \
  --in 41:33.04 --out 42:32.12 \
  --hook "먼저 믿은 게|우월이 되는 순간" \
  --source /path/to/sermon.mp4 --frames 5,30

# 2. 음성 대조용 클립
python3 $E --sermon S-20260828-EZK47 --shorts-id SS-004 \
  --in 41:33.04 --out 42:32.12 --source /path/to/sermon.mp4 --verify

# 3. 교정된 자막으로 본편
python3 $E --sermon S-20260828-EZK47 --shorts-id SS-004 \
  --in 41:33.04 --out 42:32.12 \
  --hook "먼저 믿은 게|우월이 되는 순간" \
  --source /path/to/sermon.mp4 \
  --captions sermon-office/production/SS-004/renders/captions-draft.tsv
```

**소스 영상은 채널 소유자가 공급한다.** 이 컨테이너는 YouTube 다운로드가
차단되어 있다(429 + 봇 확인, 2026-08-29 확인). YouTube Studio에서 원본을
내려받아 `--source` 로 넘긴다.
