# "농덕후" 포맷 쇼츠 제작 — 리서치 & 스크립트

## Method

- **Mode:** API mode (SCRAPECREATORS_API_KEY 사용, ScrapeCreators YouTube 엔드포인트)
- **Sources:** ScrapeCreators `/v1/youtube/search`, `/v1/youtube/channel`,
  `/v1/youtube/channel/shorts`, `/v1/youtube/video`, `/v1/youtube/video/transcript`
  (링크는 아래 표에 포함) + 보조 웹서치
- **Sample size:** 채널 쇼츠 48개(가져온 전체), 상위 3개 아웃라이어 트랜스크립트 전문 확인
- **Date:** 2026-08-30
- **Not checked:** 댓글 마이닝(stage 5), Gemini 영상 분석(음성 외 화면 연출 요소), 롱폼 영상

## ⚠️ 채널 특정 실패 — 사용한 대체 채널 고지

"농덕후"라는 이름의 유튜브 채널을 다음 방법으로 찾았지만 **정확히 일치하는 채널을 찾지 못했습니다**:

- 웹 검색 6회 (다양한 조합: "농덕후 유튜브 채널", "농덕후 채널", "농덕후 쇼츠 유튜버" 등)
- ScrapeCreators `/v1/youtube/search`로 "농덕후" 및 변형(농사덕후, 농업덕후, nongdeokhu 등) 검색 → 전부 무관한 결과("늡덕후"=농구 채널, "새덕후"=조류 채널 등 "덕후" 퍼지매칭만 반환)
- `/v1/youtube/channel?handle=농덕후` 직접 조회 → 구독자 3명의 무관한 채널로 연결됨(핸들 미등록으로 추정)

정확한 URL/핸들 확인을 요청드렸으나 "유튜브고 니가 서치해"(직접 찾으라는) 답변을 받아, 검색 결과 중 개념적으로 가장 근접한 **실존·검증 가능한 농사 브이로그 쇼츠 채널**을 대체 기준으로 사용했습니다:

> **동갑내기영농일기** — https://www.youtube.com/@yeongnong-ilgi
> "시골에서 소 키우고 농사 짓고 육아하는 영농부부" · 구독자 253K · 영상 322개 · 누적 조회수 117,904,352 · 2019-02-12 개설

이 채널이 실제 "농덕후"가 아닐 가능성이 있음을 분명히 밝힙니다. 원하시는 채널이 따로 있다면 URL/핸들을 주시면 이 리서치를 그 채널로 다시 돌리겠습니다.

## 포맷 해부 (Method: transcript 전문 인용, verbatim)

채널에는 두 개의 서로 다른 승리 포맷이 섞여 있습니다:

**포맷 A — 내레이션 슬라이스오브라이프 요리 브이로그** (1위·3위가 이 포맷, 압도적 최고 성과)
1. **훅(0-3초)**: 캐릭터/상황을 궁금증 유발형으로 제시.
   - 1위: *"내 남편은 인공수정사라서 농가 출장을 다니는데 빈손으로 집에 오는 경우가 거의 없다"*
   - 3위: *"시골에 사는 새댁인데 잠깐만... 결혼 4년 차인데 왜 마을에서 나를 새댁이라고 부르지"*
2. **재료 획득**: 이웃/농가에게서 나눔받거나 텃밭에서 직접 수확 — "시골 인심"·"자급자족" 테마 확립
3. **조리 과정**: 1인칭 내레이션으로 단계별 요리 과정을 담담하게 서술 (자막 없이 음성 내레이션 + 현장음)
4. **페이오프**: 따뜻한 마무리("짠", 가족과 함께 먹음) 또는 코믹한 반전(3위: 남편이 장난쳐서 망함)
5. **제목/캡션**: 짧은 문구 + 🔥 이모지 + `#shorts #영농부부`, 설명란엔 해시태그 + 캐주얼한 질문("~좋아하시나요?")

**포맷 B — 무언극 코미디 스킷** (2위)
- 대사 거의 없이 음악 위주, 부부 사이 장난스러운 상황극("아내 몰래 택배 받는 남편")
- 펀치라인형 캡션이 훅 역할을 대신함

포맷 A가 재현성과 성과 면에서 더 강력하므로(1·3위, 상위 3개 중 2개), 아래 신규 스크립트는 **포맷 A**를 기준으로 제작했습니다.

## 신규 쇼츠 스크립트 — "옥수수 삼십 개를 받았다"

포맷 A의 구조(궁금증 훅 → 나눔/수확 → 내레이션 조리 과정 → 따뜻한 페이오프)를 그대로 따르되, 내용은 100% 신규 창작이며 원 채널의 문구를 그대로 쓰지 않았습니다. 계절은 현재 시점(8월 말, 늦여름 옥수수·풋고추 제철)에 맞췄습니다.

**제목:** 옆집 할머니가 옥수수를 이렇게나 많이🔥 #shorts

**길이:** 약 50-55초 · **포맷:** 1인칭 내레이션 + 현장음, 자막 없음(원 포맷과 동일)

| 시간 | 내레이션(음성) | 화면(비주얼) |
|---|---|---|
| 0:00-0:04 | "옆집 할머니가 대문 앞에 뭘 놔두고 가셨다" | 대문 앞 놓인 커다란 마대자루, 손으로 여는 컷 |
| 0:04-0:08 | "설마 또 옥수수는 아니겠지 하고 열어봤는데" | 마대 안 가득 찬 찐 옥수수/생옥수수 클로즈업 |
| 0:08-0:13 | "이건 또 무슨 양이야, 서른 개는 되겠다" | 옥수수를 하나씩 꺼내 세는 손, 놀란 리액션 |
| 0:13-0:18 | "이대로 두면 다 쉬어버리니까 오늘 안에 손을 봐야 한다" | 텃밭 배경으로 이동, 앞치마 두르는 컷 |
| 0:18-0:23 | "일단 껍질 까고 수염 떼는 것부터 시작" | 옥수수 껍질 벗기는 손, 수북이 쌓인 껍질 |
| 0:23-0:30 | "반은 그냥 찌고, 반은 알만 발라내서 냉동해두기로 했다" | 찜기에 옥수수 넣는 컷 / 칼로 알 발라내는 컷 |
| 0:30-0:38 | "옥수수 알은 나중에 옥수수전 부쳐 먹을 생각" | 발라낸 알갱이를 지퍼백에 담아 냉동실에 넣는 컷 |

**설명란(캡션):**
```
#텃밭 #옥수수 #시골 #힐링 #여름간식 #자급자족

여름엔 역시 옥수수죠..?🌽
```

**제작 노트 (openmontage/voicebox로 실제 렌더할 경우):**
- 원 포맷처럼 배경음악은 잔잔하게 깔고 내레이션이 주가 되는 구조 — `voicebox` 스킬로 차분한 톤의 내레이션 보이스 캐스팅 권장
- 화면은 자막 없이 현장 컷 위주 — 실제 촬영 소스가 없다면 `asset-hunter`로 대체 스톡/아카이브 영상을 찾아야 함(옥수수 수확·찜기 장면 등은 재현 촬영이 가장 자연스러움)
- 이 포맷은 "진짜처럼 보이는 일상"이 핵심이라 AI 생성 이미지보다 실제 촬영 소재가 훨씬 잘 맞음
