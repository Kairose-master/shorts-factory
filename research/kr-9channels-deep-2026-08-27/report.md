## 1. 채널별 분해 (9/9)

### ① 로맨툰 — 서민 일상 시트콤을 웹툰으로 (124K, 중앙값 56K)

- **형식** ✅실측: 2D 웹툰 애니메이션, 고정 가족 캐릭터(경태·강경자 모자), 내레이터 없는 대화극
- **hook**: 5/5 전부 대화 인입 — *"공태야 왜 울어?"*, *"엄마 배고파. 엄마 치킨 시켜 줄게."*
- **소재가 전부 서민 경제다**: 배달 쿠폰으로 시키는 치킨, 이마트 과자담기 행사, "대신 딱 한 마리만"
- **엔진 — 캐릭터 자산**: 댓글이 캐릭터 이름을 변주하며 논다 — "곡태!"(220), "강.겅.자.씨?"(419), "강겅자 다리 왜저럼?"(720). 광고 편성조차 세계관 안에서 소화 — *"우리 로맨툰 광고 받았구나, 경태야 너도 성공했다!"*(223)
- **짠함이 웃음과 공존**: *"치킨 시켜준다고 했을때 '오늘 내 생일 아닌데?' 하는거 겁나 불쌍하노"*(824) — 가난 코미디가 조롱이 아니라 연민으로 소비됨

### ② 효잉 — 정파 공격 클립 (231K, n=6 소표본)

- **형식** ✅실측: 방송·아카이브 클립 재편집 + 논평. 특정 정치인 공격에 특화
- **성과**: top이 2.57×, 절반이 1× 미만 — **9채널 중 배수 최하위**
- **댓글**: 전원 진영 확인 — "시체팔이"(843), "멸공!!!"(700). 해석·증언·유머 없음
- **판단을 영상이 다 내리면 댓글이 할 일은 동의뿐**이라는 반례 표본. §2 참조

### ③ 책트폭행 — 인물 서사 에세이 (364K, 중앙값 42K)

- **형식** ✅실측: 정지 이미지 + 켄번스 + 내레이션. 얼굴 노출 없음
- **hook**: 결론 선언형 — *"검정 드레스를 입은 아름다운 여성은 이 그림 하나로 인생이 망가졌습니다"*(50.68×), *"잘생긴 소년들을 타락시키는 할리우드"*(13.41×)
- **엔진 — 과거→현재 자동 번역**: 할리우드 타락 영상의 최상위 댓글이 *"남 얘기할 필요 없고... 버닝썬이나 철저히 재조사하자"*(4,100). 19세기 초상화 영상에선 현대 2차 가해 논의(3,200). **영상은 연결하지 않고 댓글이 연결한다**
- 인물 옹호 서사에선 댓글이 명문을 생산: *"'이 세상은 마이클 잭슨을 가질 자격이 없다'"*(1,800)

### ④ 호밀밭의 우원재 — 역사 수정주의 논평 (564K, 중앙값 78K)

- **형식** ⚠️추론: 자료사진 + 강한 1인 논평 (얼굴 노출 가능성 높음)
- **hook**: 도발 선언 — *"한국이 패륜의 나라인 이유 이 사진을 보시죠"*(6.28×)
- **엔진**: 통념 반박("이승만 팩트체크", "영화로 역사 배우지 맙시다"). 판단을 영상이 직접 내림
- **댓글**: 이념 동조가 다수 — 다만 효잉과 달리 **사료 디테일로 논증을 보태는 층**이 있음: *"한강철교 사진은 대동강철교라지, 여름에 겨울옷이더라"*(520). 배수도 2.5~6.3×로 효잉보다 높음

### ⑤ 당신이몰랐던이야기 — 구조적 빈곤의 사건화 (1.33M, 중앙값 63K)

- **형식** ⚠️추론: 자료화면 + 차분한 내레이션
- **hook**: *"고시원은 가난의 종착지가 되었습니다"*(9.16×) — 결론 선언 후 연대기 전개
- **엔진 — 증언 유발**: 고시원 영상 댓글이 전부 **당사자 경험담**이다 — *"ㄹㅇ 고시원 들갓는데 취준생보다 할부지들이 더 많았음"*(1,300), *"라면,김치 무제한에 월30이었지"*(994), *"칸막이가 있는게 좋아.. 칸막이가 없으면…"*(1,000)
- **이 채널이 계층 콘텐츠의 교본이다**: 가난을 조롱도 동정도 하지 않고 구조로 서술 → 시청자가 자기 경험을 증언으로 얹음. 일본 소재(파파카츠)에서도 같은 문법: *"매독키즈라고 이미지 덮었으면 해결됐을텐데"*(307) — 명명(naming)의 정치까지 댓글이 짚음

### ⑥ 궁금소 — 과정 서술, 판단 유보 (997K, 중앙값 81K)

- **형식** ⚠️추론: 일러스트/자료화면 + 사건·과정 내레이션
- **top 5 배수가 43.99×~171.06×** — 9채널 중 압도적. 전부 같은 문법: 고유명사+연도+숫자로 열고, 시간순 과정 서술, **판단 없이 종료**
- *"미라가 과연 어떻게 제작될까"*(60.79×), *"화산이 폭발하면서 대피하지 못한 사람들이 그대로 화석이"*(43.99×)
- **엔진 — 댓글이 도덕을 쓴다**: 침팬지 햄(81.05×) 최상위 댓글 *"저렇게 무해한 표정인게 더 맘 아프다"*(**20,000**), *"미국의 이런 예우는 참 좋은듯"*(16,000). 영상은 사실만 서술했고 감정·판단·후일담 전부 댓글 생산

### ⑦ 달빛부부 — 완벽한 인물의 균열 (1.1M, n=13 소표본)

- **형식** ⚠️추론: 해외 인터뷰·중계 클립 재편집 + 내레이션 자막
- **hook 문법이 하나로 수렴**: *"완벽한 남자라고 불리는 오타니지만 그런 그에게도 약점이"* — **완벽 프레임 제시 → 균열 하나 공개**. top 영상(티모시 37.16×, 트럼프 금지령 15.03×) 모두 동일 구조
- **댓글**: 균열이 호감으로 전환 — *"뭔가 모자란 게 있어야 더 친근한듯"*(12). 조롱이 아니라 애정 유발 장치

### ⑧ 내손내싼 — 완곡어법 그 자체가 포맷 (96.5K, 중앙값 111K)

- **형식** ⚠️추론: 인물 사진·클립 + 수식어 누적 내레이션
- **중앙값(111K)이 구독자(96.5K)보다 크다** — 구독 기반이 아니라 탐색 피드 채널
- transcript와 댓글("이토 마유키" 등)로 보아 **일본 성인물 배우를 완곡어법으로 소개하는 채널로 보인다**. hook 5/5가 같은 문법: 직접 명명 없이 수식어를 누적 — *"확신의 일진상, 고부 갈등상… 그녀"*, *"최강 슬랜더에 우인 그녀"*, *"2계에서 산전수전"*
- **리서치 관점의 발견**: 말할 수 없는 것을 말하는 **우회 화법 자체가 알고리즘 생존 전략이자 밈**이 된 사례. 완곡어법이 시청자와의 암호 놀이가 됨
- **주의**: 성인물 인접 소재 — 참조는 화법 구조까지만. 브랜드 세이프티상 소재 모방 불가

### ⑨ 제로비 — 원가 검증 + 광기 캐릭터 (990K, 중앙값 1,136만)

- **형식** ⚠️추론: 제품 탑다운 + 손 + 자막 (얼굴 없음 추정)
- **중앙값 1,136만 — 다른 8개 채널 1위 영상보다 크다.** 편차 최소(1.97~3.37×) = 실패작이 없는 완성된 포맷
- **hook 문법**: 가격 고발 언어 + 숫자 + 질문 — *"10년 전에 3,000원이면 먹던 떡볶이를 14,000원에"*, *"고작 냉면 한 그릇에 16,000원"*, *"질소를 사면 감자칩을 준다는 포카칩"*
- **비판 언어를 그대로 인용**: "창렬칩", "걸레 빤 물" — 시중의 조롱을 hook 재료로 수입
- **노동이 콘텐츠**: 참기름을 직접 짜서 검증 → 댓글이 인물 숭배로 응답: *"부지런하고 영리한데 미친사람을 보고있는듯"*(24,000), *"똑똑한 두뇌와 광기를 실행하는 행동력"*(6,800)
- 반전 서사도 보유: 엽떡 편 — 10년 가격 동결로 *"오히려 가성비가 좋아졌다"* — 고발 채널이 재평가도 한다는 신뢰 장치

## 2. 채널 횡단 발견

### 판단 유보 축 — 이 데이터의 가장 큰 패턴

| 판단 처리 | 채널 | top 배수 | 최상위 댓글의 성격 |
|---|---|---|---|
| **영상이 판단을 비움** | 궁금소 | 171.06× | 해석·도덕 생산 (20,000 likes) |
| | 달빛부부 | 37.16× | 애정 전환 |
| | 당신이몰랐던이야기 | 16.98× | **당사자 증언** (1,300) |
| | 로맨툰 | 13.87× | 캐릭터 밈 재생산 |
| | 제로비 (질문형) | 3.37×* | 인물 숭배 (24,000) |
| **영상이 판단을 내림** | 우원재 | 6.28× | 이념 동조 + 사료 보강 |
| | 책트폭행 (선언형) | 50.68× | 현재 이슈 번역 |
| | 효잉 | 2.57× | 진영 확인만 |

*제로비는 배수가 낮아 보이나 중앙값 자체가 1,136만.

**관찰**: 판단을 비운 채널일수록 배수가 높고 댓글이 생산적이다(해석·증언·밈).
판단을 내리는 채널은 댓글이 동의 확인에 그친다. 예외는 책트폭행 — 판단(선언)은
있지만 **과거 소재에 한정**해서, 현재로의 번역은 댓글에 남겨둔다. 절충형.
채널 규모·소재가 교란 변수이므로 인과가 아니라 관찰로 기록.

### 계층·사회 소재의 작동 방식 3종 (조롱 없이)

1. **직시+증언** (당몰이): 구조를 서술하면 당사자가 증언을 얹는다
2. **코미디+짠함** (로맨툰): 서민 일상을 캐릭터로 감싸면 연민으로 소비된다
3. **고발+검증** (제로비): 가격을 겨냥하되 노동으로 증명하면 인물 신뢰가 쌓인다

셋 다 **아래를 조롱하지 않는다**. 조롱 없는 계층 콘텐츠가 이 데이터에서 작동하는 형태의 전부다.

## 3. 「말값」 미디어아트 연작 설계 — 9채널 전부를 사상(寫像)

컨셉 유지: **단어 하나가 얼마인가.** 형식은 boil 추상(먹지/종이/단일 마크/타이포) —
미디어아트 연작으로 넘버링. 각 편이 **다른 채널의 엔진 하나씩**을 빌린다.

| EP | 단어 | 빌리는 엔진 | 출처 채널 | 실측 근거 |
|---|---|---|---|---|
| No.1 시그니처 | 시그니처 | 원가 폭로 + 판단 유보 | 제로비 + 궁금소 | 완성 (2판) |
| **No.2 정통** | 정통 | **과정 서술** — "단어가 만들어지는 과정" | 궁금소 171× 문법 | 평냉 16,000원, "걸레 빤 물" — 제로비 transcript verbatim |
| No.3 프리미엄 | 프리미엄 | **완벽 프레임 → 균열 하나** | 달빛부부 37× 문법 | "완벽한 남자의 치명적 약점" 구조 이식 |
| No.4 큐레이션 | 큐레이션 | **과거 서사 → 현재 번역은 댓글에** | 책트폭행 50× 문법 | 버닝썬 댓글 4,100 — 번역은 시청자가 함 |
| No.5 국룰 | 국룰 | **증언 유발** — 구조 서술, 경험담은 댓글이 | 당몰이 고시원 문법 | 증언 댓글 1,300·1,000·994 |
