## Method

- **모드**: API 모드. ScrapeCreators(Instagram reels 검색·프로필·릴스 피드,
  6 크레딧) + Instagram CDN에서 레퍼런스 영상 직접 다운로드(무료, Apify
  불필요 — 검색 결과가 `video_versions` 원본 URL을 직접 준다).
- **표본**: `기독교`·`설교`·`말씀묵상`·`christian shorts`·`gospel reels`
  5개 쿼리로 Instagram 릴스 49건 검색 → 그중 **@churchsoulmate**(팔로워
  171,610, "기독교 대표 인스타그램 페이지") 계정을 심층 분석 대상으로
  선정. 이 계정의 최근 릴스 12편의 조회수·좋아요를 확인.
- **일자**: 2026-08-31.
- **확인 안 한 것**: TikTok·YouTube Shorts 쪽 기독교 콘텐츠는 이번 라운드에
  포함하지 않았다(Instagram 릴스만). @churchsoulmate 외 계정은 검색
  결과 요약만 봤고 심층 분석하지 않았다.

## 편집 스타일 실측 — 이 오피스 기존 포맷과의 차이

프레임을 여러 지점에서 뽑아 픽셀 단위로 측정했다(`720×1280` 원본
기준, 이하 %는 이 오피스 포맷과 비교 가능하도록 비율로 환산).

| 요소 | @churchsoulmate | 이 오피스(`shorts-format.md`) |
|---|---|---|
| 배경 | **어두운 남색(#1A2631) 캔버스** | 없음(영상이 풀블리드) |
| 영상 배치 | **인셋 박스** — 좌우 6.7%, 상단 21.2%~하단 79.7%(둥근 모서리) | **풀블리드 크롭** — 화면 전체 |
| 훅 | 박스 **위**, 어두운 배경에 흰 글씨. **인용부호로 감싼 실제 발화 1행 + 출처 1행**(예: `"그냥 있는 대로 사세요." / 故하용조 목사님 마지막 설교`) | 화면 **위**, 영상 위에 겹쳐서 흰 글씨. 오피스가 쓴 질문형 문구 |
| 하단 자막 | **흰색**, 박스(영상) 하단에 겹침 | **노란색**(`#FFE000`), 영상 하단에 겹침 — 자세 등급의 시각적 구분 장치 |
| 출처 표기 | 자막 아래 **항상 떠 있는** 작은 회색 줄("故하용조 목사 \| 온누리교회") | 없음 — 출처는 엔드카드에만 등장 |
| 엔드카드/CTA | **없음** — 설교 내용에서 그냥 끝난다 | 있음 — 날짜·본문·교회명 3.0~3.5초 |
| 해상도 | 720×1080 | 1080×1920 |

**가장 큰 차이는 "풀블리드 크롭" 대 "박스 인셋"이다.** 이 오피스는
지금까지 화면 전체를 설교 영상으로 채우는 것을 기본값으로 삼아 왔는데,
이 레퍼런스는 오히려 영상을 **작게 보여주고** 남는 공간을 어두운
배경 + 텍스트로 채운다 — 유튜브 쇼츠보다 릴스/틱톡에서 더 흔히 보이는
문법이다.

## 실험 — EXP-E04, 같은 소재로 두 포맷 비교

**가설**: 박스 인셋 + 흰 자막 + 상시 출처 표기(레퍼런스 스타일)가
이 오피스의 풀블리드 + 노란 자막(기존 포맷)보다 릴스/틱톡에서 더
자연스럽게 읽힌다.

**변수**: 레이아웃(박스 인셋 vs 풀블리드). **통제**: SS-012와 완전히
같은 소재·자막·훅 문구·소스 영상(엡5:15-20, 장선기 목사) — 레이아웃
하나만 바꿨다.

- **A팔(기존)**: `SS-012` — 이미 완결·QC 44/45(이 오피스 최고점).
- **B팔(신규)**: `EXP-E04` — 새 렌더러(`production/_engine/build_short_boxed.py`,
  이번 실험 전용, 기존 `build_short.py`를 대체하지 않음)로 같은 소재를
  박스 인셋 스타일로 재구성.

렌더 중 발견한 것 — **레퍼런스의 "마지막 설교"라는 훅 문구를 그대로
가져다 쓸 뻔했다.** 하용조 목사님은 실제로 그 설교 직후 별세하셨지만,
장선기 목사님은 아니다 — 문구를 그대로 베끼면 "장선기 목사 마지막
새벽강해"라는 **사실이 아닌 주장**이 될 뻔했다(헌장 2번 규칙 정면
위반). 렌더 직후 발견해 "장선기 목사 · 엡5:15-20 새벽강해"로 고쳐
재렌더했다 — **레퍼런스의 문구 구조는 베껴도, 문구의 사실적 내용까지
베끼면 안 된다**는 걸 이번에 직접 확인했다.

**아직 안 한 것**: 둥근 모서리·그림자는 ffmpeg 순정 필터로 비용이
커서 이번 1차 실험에서는 생략했다(직각 박스로만 비교). 실제 게시
전 승인이 나면 다듬을 부분이다.
