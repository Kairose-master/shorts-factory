# 늡덕후 포맷 적용 — 소재 교체 버전

늡덕후의 구조("짧은 하이라이트 모먼트 원본 그대로 + 반전형 한국어 훅 제목 + 한 줄 캡션")를
NBA 대신 **합법적으로 소싱 가능한 실제 아카이브 푸티지**에 적용했습니다.

## 소재 선정 근거

- NBA 클립은 저작권상 확보 불가 → 이 워크스페이스의 무료 렌더 경로가 실제로 커버하는 소스는
  Archive.org / NASA / Wikimedia 공공 도메인 아카이브 (CLAUDE.md "The render layer" 참고)
- NASA가 제작한 영상은 미국 정부 저작물로 별도 표기가 없는 한 퍼블릭 도메인
- 늡덕후처럼 "글로벌하게 유명한 단일 순간 + 원본 음성 그대로"가 성립하려면 소재도 그만큼
  상징성이 커야 함 → **아폴로 11호 새턴 V 발사** 선택 (실존·검증 가능한 실제 사건)

## 확보 가능한 실제 소스 (검증됨)

- **클립**: Apollo 11 Launch, 1969-07-16 — Internet Archive
  https://archive.org/details/apollo-11-launch-07-16-1969 (NASA, 퍼블릭 도메인)
- 발사일 1969-07-16 기준 오늘(2026-08-30)로부터 **57년 전**

## 쇼츠 스크립트 — "57년 전, 이미 정해졌던 인류의 순간"

늡덕후의 "반전/재조명형" 제목 공식(`2년전 이미 정해졌던 NBA 덩크 챔피언`)을 그대로 적용.

| 항목 | 내용 |
|---|---|
| **제목** | 57년 전, 이미 정해졌던 인류의 첫걸음 |
| **길이** | 약 28-35초 (늡덕후 표본 범위 19-53초 내) |
| **원본 클립 구간** | 새턴 V 로켓 점화(ignition) ~ 발사탑 이탈(tower clear) 구간 — 위 Archive.org 소스에서 해당 구간 트리밍 |
| **오디오** | 원본 그대로 사용 — 미션 컨트롤 카운트다운 교신 음성("We have a liftoff...") + 실제 발사 굉음. 별도 한국어 내레이션 없음(늡덕후 포맷과 동일) |
| **설명란 캡션** | "이게 57년 전이라고?ㄷㄷ" |
| **해시태그** | #아폴로11호 #NASA #우주 #Shorts |

### 편집 지시 (openmontage로 렌더 시)

1. Archive.org 소스 클립을 다운로드 (`archive.org/details/apollo-11-launch-07-16-1969`, 퍼블릭 도메인이므로 재사용 가능)
2. 점화~발사탑 이탈 구간만 트리밍 (약 25-30초)
3. 원본 오디오 유지, 별도 배경음악·내레이션 추가하지 않음 — 이 포맷의 핵심은 "가공 없는 원본의 무게감"
4. 영상 시작 1-2초에 제목 텍스트 오버레이("57년 전, 이미 정해졌던 인류의 첫걸음") — **단, 늡덕후 실제 영상에 이런 자막 카드가 실제로 붙어있는지는 화면을 직접 열어보지 않아 확인하지 못했습니다.** 트랜스크립트(음성 기반)만으로는 확인 불가한 부분이라, 이 자막 오버레이는 동종 하이라이트 장르의 일반적 관행을 따른 제 판단이며 늡덕후 채널에서 실측 확인된 사실은 아닙니다.
5. 9:16 세로 크롭 — 로켓 발사 화면은 보통 4:3/16:9라 세로 크롭 시 로켓 몸체가 잘리지 않게 좌우 여백보다 상하 크롭 우선

### 이 적용의 한계

- 늡덕후는 "한국 선수 정체성 훅"(이현중, 송태섭 등)으로 로열티를 만드는데, 이 소재엔 그런 인물 앵커가 없음 → 반복 시리즈로 만들려면 "역대 우주비행사" 등 인물 축을 새로 설계해야 함
- 화면 편집 스타일(자막 폰트, 워터마크, 컷 타이밍)은 실측하지 못했으므로 위 4번 항목은 가정임을 다시 한번 명시
