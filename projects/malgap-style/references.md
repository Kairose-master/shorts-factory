# 미디어아트 레퍼런스 — 「말값」 연작의 계보

레퍼런스는 두 층이다: **채널 실측**(reference-board.png, 썸네일 10장)과 **미디어아트
계보**(이 문서). 후자는 웹 조사로 확인한 실존 작가·작업이며, 모사가 아니라 어법의
계보 표기다 (canvas-design 스킬 규칙: 기존 작가 모사 금지).

## 1. Jenny Holzer — 아포리즘을 상업 매체에 되돌려 넣기

- **Truisms** 연작(1977~): 한 줄 경구를 LED 전광판·광고판·건물 투사로 공공 공간에 배포.
  정보 시대와 소비주의를 **그 매체 자체를 탈환해** 비판
- 구겐하임 로툰다의 한 줄 중에 **"MONEY CREATES TASTE"** 가 실제로 있다 —
  「말값」의 논지("단어가 값을 만든다")가 이 계보의 직계임을 확인
- 이식한 어법: **각주의 목소리** — 화면 하단의 경구형 한 줄
  ("정보가 비대칭일 때 신호에 값이 붙는다"), 판단이 아닌 관측의 문장형

## 2. Barbara Kruger — 붉은 띠 위의 선언문

- 흑백 사진 + **붉은 바탕·흰 Futura 선언문** ("I shop therefore I am")로
  소비주의를 겨냥한 개념 미술의 표준 어법
- 이식한 어법: 엔드카드의 **선언 바** — "빈칸은 당신이 채우세요"를 붉은 띠·흰 글자로.
  구도·서체·문장 전부 원작과 다르게 새로 만들었고, 어법(붉은 띠의 2인칭 선언)만 계승
- 연작의 먹/종이/인주 팔레트가 Kruger의 흑/백/적과 같은 계열이라는 점도
  사후적으로 확인 — 우연이지만 계보 표기의 근거

## 3. 채널 실측과의 합류점

Holzer/Kruger의 공통 전략 = **판단을 관객에게 넘기는 텍스트**. 9채널 리서치의
최대 발견(판단 유보 축 — 궁금소 171×, 댓글이 결론을 생산)과 정확히 같은 기제다.
미디어아트 계보와 숏폼 실측이 같은 결론을 가리키므로, 이 연작의 핵심 장치는
**빈칸**으로 확정한다.
