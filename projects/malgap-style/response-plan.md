# 「말값」 반응 설계 — 실측 근거별

"반응이 있으려면"에 대한 답. 전부 이 워크스페이스의 리서치 실측에 근거를 둔다.

## 영상 안에 심은 것 (v-final에 반영됨)

| 장치 | 근거 | 반영 |
|---|---|---|
| **첫 문장에 가격** | hook 집계 26/45 고유명사+숫자 | "이 요거트 컵은 삼만 원이 넘습니다" — 1초 내 숫자 |
| **간격 ≤0.5s, 무발화 씬 0** | viral-youtube-shorts 리텐션 게이트(30초 미만 ~65% APV 밴드) + 사용자 지적 | No.1 31.8s / No.2 28.8s, 씬=내레이션+0.5s |
| **모든 씬이 인과 연결** | 무맥락 지적 | "그런데 이름이 붙으면 값이 달라집니다" 류 연결어를 대본에 삽입 |
| **빈칸 명시 위임** | 궁금소 판단 유보(171×, 41,000 likes 댓글이 결론 생산) + Ondrej tier list의 누락 정정 반응(§4f) | 엔드카드 선언 바 "빈칸은 당신이 채우세요" — 채울 수 있는 빈칸은 정정 본능을 당긴다 |
| **루프 이음새** | Shorts 반복 재생 가중 | 끝(빈칸 등식) → 처음(가격 기념비)으로 시각 순환 |
| **음량 -14 LUFS** | 플랫폼 정규화 기준 | 양편 -13.8/-13.9 |

## 발행 운영 (영상 밖 — 발행 시 실행할 것)

1. **고정 댓글 = 다음 단어 공모**: "No.3 후보 — 프리미엄 / 오마카세 / 큐레이션.
   더 비싼 단어를 아시면 답글로." → 궁금소의 고정댓글 퍼널(§4f, 2,300 likes) +
   당몰이의 증언 유발을 합친 재귀 구조. 댓글이 다음 화 소재가 되는 시리즈 엔진
2. **캡션은 질문 1행**: "당신이 낸 최고 말값은?" — viral-captions-and-ctas의
   답글 유도형. "좋아요/구독" 류 일반 CTA 금지(도달 억제 패턴)
3. **연작 리듬 고정**: 같은 구조·같은 인주·같은 빈칸의 반복이 캐릭터 자산의 등가물
   (로맨툰 §4e — 반복 요소를 댓글이 재생산). 포맷 자체가 캐릭터
4. **빈칸이 채워지는 순간이 2차 콘텐츠**: 댓글이 원가를 채우면 그 댓글을 다음 화
   도입에 인용(제로비의 비판 언어 수입 기법) — 단, 검증 후
5. **주의**: 이 모든 것은 패턴 기반 확률 개선이지 바이럴 보장이 아니다
   (워크스페이스 하드 룰 5)
