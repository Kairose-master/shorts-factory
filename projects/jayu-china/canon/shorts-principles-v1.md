# 자유중국 Shorts 제작 원칙 v1.0 (사용자 정본 — 변경 금지)

목표: "설명을 잘 만든 영상"이 아니라 첫 1초에 인지부조화를 만들고, 60~70초 동안 그 역설을 역사적 인과로 납득시키는 영상.

## 1. 결론을 숨기지 말고 첫 1초에 훔쳐 보여준다

기존 EP1은 대략: 1946 → 역사 전개 → 정치변화 → 보수=복지 / 진보=민영화

앞으로는: 보수=복지 / 진보=민영화 → ??? → 1946 → 인과 전개 → 결론 회수

가장 충격적인 장면은 **보상(reward)이 아니라 미끼(hook)**다.

## 2. 첫 문장은 세계관 설명이 아니라 현실과의 충돌이어야 한다

피해야 할 시작: "1946년 국민당 정부는…"

좋은 시작:
- "이 세계에서 한국 보수는 친중입니다."
- "중국 진보파는 민영화를 주장합니다."
- "미국과 중국은 둘 다 자유민주주의 국가입니다. 그런데 신냉전을 벌입니다."

시청자의 첫 반응은 "왜?"여야 한다.

## 3. 3초 안에 전제까지 준다

충격만 던지고 세계관을 이해 못 하면 그냥 넘긴다.

- 0~1초: 역설
- 1~3초: 세계관 전제
- 3~6초: 설명 약속

예: "이 세계에서 한국 보수는 친중입니다." / "왜냐하면 1949년, 중국 공산당이 패배했거든요." / "그러면 한국 정치가 완전히 뒤집힙니다."

## 4. 한 영상에는 하나의 질문만

EP 하나에서 설명할 것은 하나다. EP2라면 오직: "왜 자유중국의 보수가 국가개입을 지지하는가?" 나머지 설정은 이 질문에 필요한 만큼만 등장시킨다.

## 5. 역사 설명은 연표가 아니라 인과사슬로 만든다

연도 나열은 교과서가 된다. 항상: A 때문에 B → B 때문에 C → 그런데 C가 D라는 역설을 낳음.

예: 국민당 승리 → 반공 개발국가 → 국가주도 산업화 → 민주화 → 기존 체제 수호세력이 국가개입을 방어 → 보수=국가개입 → 개혁세력이 시장화를 요구 → 진보=민영화

그러면 설정이 아니라 논증이 된다.

## 6. 3~5초마다 시각적 상태를 변화시킨다

지도 → 연표 → 문서 → 그래프 → 인물 → 정당 → 정책축처럼 정보의 표현 방식 자체를 바꾼다. 단, 화면전환을 위한 화면전환은 금지. **새로운 인과관계가 등장할 때 화면도 변한다.**

## 7. 자막은 읽는 글이 아니라 보는 글

한 화면에 핵심 문장은 가급적 하나. 설명을 자막에 다 넣지 말고 내레이션이 설명하고 화면은 구조를 보여준다.

## 8. 고퀄리티보다 정보 위계를 우선한다

EP1 정도의 그래픽 퀄리티면 이미 충분하다. 제작시간을 더 투입한다면 그래픽 디테일 +20%보다 **첫 2초 +50%**에 투자한다.

## 9. 매 편 중간에 두 번째 훅을 넣는다

약 20~30초 지점에 새로운 반전. Hook 1 → 설명 → Hook 2 → 설명 → Payoff 구조. 쇼츠 전체를 하나의 훅으로 버티지 않는다.

## 10. 마지막 10초는 다음 편의 광고가 아니라 새로운 모순

나쁜 엔딩: "다음 편에서는 자유중국의 보수를 알아보겠습니다."
좋은 엔딩: "그런데 문제가 하나 생깁니다." / "이 세계의 한국 보수는 친중입니다." CUT.

## 고정 70초 포맷

| 구간 | 기능 | 예 |
|---|---|---|
| 0~2초 | WTF | "중국 진보파는 민영화를 주장합니다." |
| 2~7초 | 전제 | "공산당이 국공내전에서 패배한 세계라면 가능합니다." |
| 7~20초 | 원인 A | 역사가 갈라진 지점 |
| 20~35초 | 원인 B | 그 변화가 제도화되는 과정 |
| 35~45초 | Second Hook | "그런데 여기서 정치가 뒤집힙니다." |
| 45~60초 | Payoff | 처음 보여준 역설을 인과적으로 설명 |
| 60~67초 | 확장 | "그리고 이 변화는 중국에서 끝나지 않습니다." |
| 67~70초 | 다음 모순 | "한국 보수는 친중이 됩니다." CUT. |

## 시리즈 전체의 가장 중요한 규칙

**낯선 세계를 설명하지 않는다. 익숙한 상식을 하나 깨고, 왜 깨졌는지를 설명한다.**

제작할 때마다 딱 세 가지를 먼저 적는다:

1. 이 영상에서 현실과 가장 반대되는 사실은 무엇인가?
2. 어떤 역사적 인과가 그것을 만들어냈는가?
3. 다음 편에서 깨뜨릴 상식은 무엇인가?

이 세 문장에 답하지 못하면 아직 제작에 들어가지 않는다.
