## 문서 1: 「자유중국 시즌1 콘텐츠 제작 가이드」 v1.0

### 기존 바이블과 일치 (변경 없음)
- 세계관 정본 전부: 국민당 개발국가→점진 민주화, 한국전쟁 중공군 부재, 통일
  한국의 대륙 편입, 한국 보수=친중/진보=자주, 일본 해양화·재무장, 미중 = 두
  자유세계의 신냉전, 대만=연방주의 쟁점, 홍콩=constitutional integration
- 정치 블록 구성, 보수·진보 내부 분파 요구, 역설 목록

### 새로 채택 (기존 바이블에 없던 것)
1. **§9 제목·썸네일·훅 규칙**: 제목=질문형 정치 문장 / 썸네일=2–6단어 역설
   단서 / 둘이 같은 정보 반복 금지 / 첫 15초 내 대체역사 명시, 긴 디스클레이머
   금지 / "이 세계의"로 현실 정치 주장과 구분 → **성문화. 기존 60훅·36썸네일은
   규칙 적합 확인됨(훅≠제목, 썸네일 전부 2–6단어)**
2. **§10 EP2 비트 설계** (Cold Open 공약 낭독→오해 유도→역사 회수→분파→반례→
   생활 장면→"무엇이 '기존 질서'였는지가 달랐습니다") → EP2 제작 시 이 비트를
   그대로 따른다
3. **§11 매화 체크리스트 9항** → 제작 게이트로 채택. 주의: 기존 EP1 숏폼판은
   "최소 1명의 시민/정치인 등장" 항목 미충족 — 본편 제작 시 보완 필요 사항으로 기록
4. **§12 파일럿 성과 해석 가이드** (CTR 약함→역설 재패키징 등) → response-plan에 편입
5. **부록A 훅 문장은행 / 부록B 금지표현** ("그냥 좌우 반대 세계" 금지, "자유중국=
   좋은 중국" 금지 등) → 최상위 금지 목록으로 채택

### 변경 (사용자 정본 우선)
- **EP12 엔딩 교체**: 기존 바이블의 1913 호광철도 채권 소송 브릿지 + PERSON A
  포스트크레딧 → **폐기**. 정본 §13: 2080 총선 결과 화면 + "여러분은 이 정당들을
  왜 자꾸 좌파/우파 한 줄에 세우려 했을까요?" 질문만 남긴다. 채권 소송 소재는
  철학편 국가/token 챕터의 사건 후보로 이관
- **시즌 2 정체 변경**: 국가동일성 시즌 → **「자유중국의 철학」** (문서 2).
  S1=데이터/사건, S2=그 데이터에서 철학 추출이라는 2층 구조
