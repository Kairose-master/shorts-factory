# 자유중국 리마스터 v2 스펙 — 레퍼런스: 숫자로 보는 역사 「히틀러가 이겼다면?」 (4e0-Xdl15ww)

편집장 지시 (2026-08-29): "이 정도 퀄리티로 만들어. 4편부터 리마스터해."

## 레퍼런스에서 확인한 것 (실제 프레임 4장 검수: oar2/sd1/sd2/sd3)

1. **씬 일러스트** — 매 씬이 '다이어그램'이 아니라 '장면'이다. 손그림 카툰:
   둥근 흰 얼굴 + 점 눈 캐릭터(군복·헬멧 등 의상 디테일), 숲/해변/불타는 도시
   같은 배경이 통일된 어두운 팔레트로 그려져 있고, 외곽선이 굵다.
2. **고정 2줄 타이틀 헤더** — 흰 볼드 1줄 + 형광(그린) 강조 1줄, 영상 내내 상단 고정.
3. **자막 칩** — 검은 박스 + 흰/노랑 텍스트, 내레이션 구(句) 단위 동기화.
   구가 짧다 ("거길 거쳐서", "덩캐르크 이후", "하나 되진 않으니까요").
4. **프레임-인-프레임** — 카드형 씬은 뒤에 블러 확대판을 깔아 9:16을 채운다.
5. 실사 필름 스틸 교차 편집은 레퍼런스 고유 요소지만 저작권상 채택하지 않음
   (자유중국은 가상 역사라 실사가 성립하지도 않음) — 일러스트로 전량 대체.

## v1(현재 EP4~12)과의 격차 → v2에서 바꿀 것

| 항목 | v1 | v2 |
|------|----|----|
| 씬 화면 | 타이포+도형 다이어그램 | **일러스트 장면**(캐릭터 1~3 + 배경) 위에 정보 요소를 얹음 |
| 자막 칩 | 글자수 비례 추정 타이밍 | **edge-tts WordBoundary 실측 타이밍** (구 단위 시작시각 일치) |
| 타이틀 밴드 | 유지 (흰+노랑 2줄, 세계관 라벨) | 동일 — 채널 브랜드 유지 |
| 배경 | night 그라데이션 | 씬별 일러스트 배경 (거리·항만·역사·의사당·투표소·숲) |
| 카드 씬 | 검정 바탕 | 프레임-인-프레임 (블러 확대 배경) |

## 구현

- `remaster/char_kit.py` — PIL 일러스트 킷. 캐릭터(head/expr/outfit/pose),
  배경(street/harbor/rail/hall/room/forest), 소품(train/ship/crane/ballot/compass).
  외곽선 굵기 8~12, 팔레트는 noir_kit NIGHT 계열과 호환되는 저채도 + 포인트색.
- `remaster/vo_kit.py` — edge-tts 재생성 + WordBoundary 캡처 →
  `vo/lines.json`에 칩별 (텍스트, 시작, 길이) 실측 스케줄 기록.
- 각 EP: `ep{N}-short/render_v2.py` (씬 구성만 EP별, 킷 공유),
  결과물은 `jayu_ep{N}_final.mp4` 교체. VO 대본·씬 구조·정본 준거는 v1 그대로
  (리마스터 = 시각 품질만, 내용 불변).
- 파이프라인 나머지 동일: loudnorm -14 → QC 프레임 시트 육안 검수 → SendUserFile
  → queue.json에 remaster 표기 → 커밋/푸시. 발행은 하지 않는다.
