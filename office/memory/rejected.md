# Rejected Ideas

Nothing rejected yet.

**Never delete. Never renumber.** An idea deleted today is regenerated in six
weeks by an Office with no memory of it, and re-making a known-bad video is the
single most expensive mistake this Office can make.

## Row format

```
ID              HS-000
Rejected at     stage — idea | script | scene-plan | QC | post-publish
Reason          in plain words. "Reads as crypto-shill" is retrievable.
                "QC-3" is not.
Worth keeping   the one shot, line, or framing that was good
Revisit if      the condition that would make this viable again
```

`Worth keeping` is not sentimental. A rejected video almost always contains one
usable line or one usable shot, and losing those is losing the only value the
cycle produced.
