# SOP — Production pipeline

Fourteen steps. Steps 1–5 are thinking, 6–10 are making, 11–14 are learning.
Full skill-ownership table: `.claude/skills/openmontage/references/office-integration.md`.

## Per approved concept

1. **3–10 hook variants** — `viral-hooks`. All logged to `memory/hooks.md`, even
   the bad ones. A hook rejected today gets proposed again in six weeks by an
   Office that did not write it down.
2. **Select one** — `hook-anatomy` critiques the batch. Record *why* the winner
   won; that reason is the reusable asset, not the line.
3. **Script** — `viral-short-form` for shape, then the platform skill for tuning.
   15–45s. Structure is one of:
   - QUESTION → SURPRISE → DEMO → PAYOFF
   - PROBLEM → EXPERIMENT → RESULT
   - HOOK → ESCALATION → REVEAL → CTA
4. **Shot list** — every shot gets a duration, a source, and the one thing it
   must show. A shot with no `MUST CONTAIN` is a shot that will be cut later.
5. **Asset ledger** — mark each asset `free`, `paid`, or `HUMAN`. Total the paid
   ones. This number goes in the approval request.
6. **— GATE —** human approves the scene plan. Nothing paid runs before this.
7. **Assets** — `openmontage` (generate/source), `penpot` (static furniture),
   `aicron` (HUMAN, paid, only if the free path genuinely cannot).
8. **Captions** — burned in, always. Most of the audience watches muted.
9. **Voiceover when appropriate** — `voicebox`. Silence is a legitimate choice;
   a montage with a music bed often outperforms narration for Pillar G.
10. **Assemble + render** — `openmontage`, 1080×1920.
11. **QC** — `sop/quality-control.md`. Reject freely.
12. **Package** — `viral-captions-and-ctas` per platform. Native copy per
    platform; never cross-post one caption.
13. **Approval request** — the render, the QC verdict, the caption, the target
    account, the publish time. Then **stop and wait**.
14. **Measure → learn** — `sop/analytics-loop.md`.

## Defaults

- 15–45s. Under 15s only for Pillar H.
- 9:16, 1080×1920, always.
- Movement inside the first 500ms. A static opening frame is a skip.
- No intro. No logo before the hook. The logo, if any, goes at the end card.
- One idea per video. A second idea is a second video.

## Experiment discipline

Change **one** variable per pair. Same concept / different hook. Same hook /
different visual. Technical vs. narrative. Founder POV vs. agent POV. Serious vs.
meme. 15s vs. 30s.

Two arms, one variable, logged in `memory/experiments.md` before publishing —
not after, because a hypothesis written after the numbers arrive is not a
hypothesis.
