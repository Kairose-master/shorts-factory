# SFX library

Two sources, one library.

## 1. Synthesised pack — available now, no key

14 sounds in this directory, generated by `_generate.py`.

```bash
python3 office/asset-library/sfx/_generate.py     # byte-identical every run
```

**Owned outright.** `license: proprietary-owned`, `commercial_use: true`, no
attribution, no third-party terms. That is a *stronger* position than CC0, not a
compromise — nothing here can ever be re-licensed, taken down, or turn out to
have been uploaded by someone who did not own it.

| Sound | For |
|---|---|
| `click` · `tick` | counter steps; `tick` is the softer one for fast runs |
| `payment` · `cash` | money moving; `cash` for a treasury-level change |
| `success` | PASS, verified, settled |
| `failure` | FAILED — deliberately flat, never comic |
| `warning` | **REVISE / INCONCLUSIVE** — the third verdict state |
| `notification` | a card appears, an agent activates |
| `impact` | a stamp lands, a hard cut |
| `whoosh` · `transition` | movement between states, scene change |
| `typing` | a prompt being typed |
| `digital` | an agent thinking |
| `office-ambience` | 6s loopable bed, mix ~-30 dB under VO |

`warning` exists because the Office needs a sound for a verdict that is neither
pass nor fail. A two-sound pack would push every ambiguous outcome toward
`failure`, which is the untyped-verdict mistake that got HS-006 blocked, made
audible.

**Verified, not assumed:** peaks at −1.0 dBFS with no clipping; regeneration is
byte-identical; and the spectra were checked against their descriptions —
`success` rises, `failure` descends, `payment` shows its three partials. The
`whoosh` sweep is genuine in construction but subtle at 0.38s and reads mostly as
a swell; that is noted rather than overclaimed.

## 2. Freesound / CC0 — BLOCKED

`sandraschi/sfx-mcp` is vendored at `vendor/sfx-mcp` (audited: MIT, talks only to
`freesound.org/apiv2`, hard-filters `license:"Creative Commons 0"` in the query).

```
BLOCKED: FREESOUND_API_KEY_REQUIRED
```

Get one free at <https://freesound.org/apiv2/apply>, then:

```bash
echo 'FREESOUND_API_KEY=...' >> .env          # never committed
claude mcp add sfx -- uv run --directory vendor/sfx-mcp sfx-mcp
```

**What it adds that synthesis cannot:** texture with a performance in it — real
room tone, mechanical noise, anything recorded rather than computed. Reach for it
when a shot needs to sound like a *place*. For UI events, synthesis is better:
cheaper, tighter, and licence-clean by construction.

**Do not re-download per video.** Cache into this directory, dedupe on
`content_hash`, and record every file in `sfx-manifest.json` with its Freesound
id, uploader and licence.
