# 윈도우에서 처음부터 — 쇼츠 만들기 전체 순서

새 윈도우 PC에 아무것도 없는 상태에서 시작해, 쇼츠 3편이 나오고, 자막까지
고치는 데까지. **1부는 딱 한 번만**, 2부부터는 만들 때마다 반복한다.

전부 무료다. API 키가 하나도 필요 없다.

**이 문서 하나면 된다.** 설치 → 유튜브에서 설교 가져오기 → 쇼츠 3편 → 자막 수정까지.

| | 무엇을 | 언제 |
|---|---|---|
| **1부** | 도구 설치 · 확인 | 딱 한 번 |
| **2부** | 영상 고르기 → 전사 → 구간 선별 → 자막·엔드카드 렌더 | 만들 때마다 |
| **3부** | 자막 글자 고치고 다시 렌더 · 구간 조정 · 엔드카드 수정 | 마음에 안 들 때 |


- 윈도우 10 또는 11, **64비트**
- 여유 공간 **20GB** — 전사 모델 3GB, 예배 영상 한 편 1GB 정도
- 인터넷

> **맥과 다른 점 하나:** 윈도우에는 리눅스식 명령창이 없어서 **Git Bash** 라는
> 것을 깔고 그 안에서 작업한다. 검은 창 하나만 쓰면 되니 어렵지 않다.
> 일반 `명령 프롬프트`나 `PowerShell` 이 아니라 **Git Bash** 를 쓴다.

# 1부 · 설치 (한 번만, 40분~1시간)

## 1. Git for Windows

<https://git-scm.com/download/win> 에서 받아 실행한다.

설치 중 선택지가 많이 나오는데 **전부 기본값 그대로 `Next`** 를 누르면 된다.
딱 하나만 확인한다 — `Adjusting your PATH environment` 화면에서
**"Git from the command line and also from 3rd-party software"** 가 선택돼
있어야 한다. 기본값이 그것이다.

설치가 끝나면 **시작 메뉴에서 `Git Bash` 를 찾아 연다.**

검은 창이 뜨고 `$` 로 끝나는 줄이 보인다. **여기가 앞으로 작업할 곳이다.**
아래 명령들은 한 줄씩 복사해 붙여넣고 `Enter`.

> Git Bash에서 붙여넣기는 `Ctrl` + `V` 또는 **마우스 오른쪽 버튼 → Paste**.
> 회색 상자 안의 것만 복사한다. 설명 문장은 같이 복사하지 않는다.

확인:

```bash
git --version
```

## 2. Python

<https://www.python.org/downloads/windows/> 에서 최신 3.x를 받는다.

**설치 첫 화면에서 맨 아래 `Add python.exe to PATH` 를 반드시 체크한다.**
이걸 놓치면 뒤가 전부 안 된다. 체크하고 `Install Now`.

Git Bash를 **닫고 새로 연 뒤** 확인:

```bash
python --version
```

버전이 안 나오고 아무 반응이 없으면 PATH 체크를 놓친 것이다. Python을 다시
설치하면서 그 칸을 체크한다.

## 3. Node.js와 Claude Code

<https://nodejs.org> 에서 **LTS** 버전을 받아 설치한다. 전부 기본값.

Git Bash를 **닫고 새로 연 뒤**:

```bash
npm install -g @anthropic-ai/claude-code
```

```bash
claude
```

브라우저가 열리면 Claude 계정으로 로그인한다. 끝나면 `/exit` 로 나온다.

> **Claude 구독이 있으면 추가 비용이 없다.** 쇼츠 구간을 고르는 데만 쓴다.

## 4. 프로그램 받기

```bash
cd ~
```

```bash
git clone -b claude/shorts-creation-automation-0xaii8 https://github.com/Kairose-master/shorts-factory
```

```bash
cd ~/shorts-factory
```

> `~` 는 `C:\Users\내이름` 을 뜻한다. 파일 탐색기에서 찾으려면 거기 있다.

## 5. 도구 설치

```bash
bash scripts/setup_render_env.sh --with-whisper
```

**20~40분 걸린다.** 영상 편집기(ffmpeg), 유튜브 다운로더(yt-dlp), 한국어 음성
인식 프로그램과 모델(3GB)을 받는다.

끝나면 마지막에 `export` 로 시작하는 **두 줄**이 나온다. 그 두 줄을 넣는다:

```bash
echo 'export PATH="$HOME/whisper:$PATH"' >> ~/.bashrc
```

```bash
echo 'export WHISPER_MODEL="$HOME/whisper/ggml-large-v3.bin"' >> ~/.bashrc
```

**Git Bash를 완전히 닫고 새로 연다.**

> 모델 내려받기가 실패하면 브라우저로 직접 받아도 된다.
> <https://github.com/ggml-org/whisper.cpp/releases> 에서
> `whisper-bin-x64.zip` 을 받아 `C:\Users\내이름\whisper` 에 풀고,
> <https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3.bin>
> 을 같은 폴더에 `ggml-large-v3.bin` 이라는 이름으로 저장한다.

## 6. 확인

```bash
cd ~/shorts-factory
```

```bash
python scripts/sermon_shorts.py doctor
```

이렇게 나와야 한다:

```
=== Tier 0 toolchain (Windows) ===
  OK    ffmpeg       C:\Users\…\imageio_ffmpeg\binaries\ffmpeg-win-x86_64.exe
  OK    yt-dlp       C:\…\python.exe -m yt_dlp
  OK    whisper      C:\Users\…\whisper\whisper-cli.exe
  OK    claude       C:\…\claude
  OK    korean font  2 file(s) in …\assets\fonts
  OK    whisper model C:\Users\…\ggml-large-v3.bin
  n/a   GEMINI_API_KEY not needed — whisper handles transcription
```

- `ffmpeg` 경로가 길고 이상해 보여도 정상이다. 파이썬 안에 들어 있는 것을 쓴다.
- `yt-dlp` 가 `python.exe -m yt_dlp` 로 나오는 것도 정상이다.
- `GEMINI_API_KEY` 가 `n/a` 인 것도 정상이다. whisper가 있으면 안 쓴다.

마지막으로 실제 렌더가 되는지 본다. 인터넷 없이 30초, 무료:

```bash
bash scripts/smoke_test_render.sh
```

`PASS` 가 나오면 설치 끝이다.

# 2부 · 쇼츠 만들기 (만들 때마다)

## 매번 하는 것

시작 메뉴 → **Git Bash** 를 연다. 그리고:

```bash
cd ~/shorts-factory
```

```bash
git pull
```

## 플랜은 둘, 하나만 고른다

| | 플랜 A — 알아서 | 플랜 B — 내가 지정 |
|---|---|---|
| 영상 | 채널에서 무작위로 뽑음 | 내가 주소를 넣음 |
| 언제 | 아무거나 하나 | 이번 주 설교를 꼭 |

### 플랜 A

```bash
bash scripts/shorts-auto.sh
```

아직 안 만든 주일예배 중 하나를 뽑아 렌더까지 간다. 끝.

뭐가 남았는지 먼저 보려면 (무료):

```bash
python scripts/sermon_shorts.py sermons
```

### 플랜 B

유튜브에서 `방배동 예심교회` → **실시간 스트림** 탭 → 설교를 열고 주소 복사.
주일예배는 "동영상" 탭이 아니라 실시간 스트림 탭에 있다.

```bash
bash scripts/shorts-url.sh "https://www.youtube.com/watch?v=여기에붙여넣기"
```

주소를 **큰따옴표로 감싼다.** 유튜브 주소의 `?` 와 `&` 는 따옴표가 없으면
셸이 먼저 먹어버린다.

## 기다리기

```
━━ 1/4 원본 내려받기   5~15분
━━ 2/4 한국어 전사    20~60분   ← 제일 오래 걸린다
━━ 3/4 구간 선별      2~5분
━━ 4/4 렌더          5~15분
```

**전체 40분~1시간 반.** 맥의 M1/M2 칩과 달리 윈도우 PC는 그래픽카드 없이
CPU로만 돌리는 경우가 많아 전사가 더 걸릴 수 있다. 예배가 100분인 편도 있다.
2단계에서 몇 분간 글자가 안 나와도 정상이다. 멈춘 게 아니다.

- Git Bash 창을 **닫지 말 것.** 닫으면 중단된다.
- PC가 절전으로 들어가면 멈춘다. 설정 → 시스템 → 전원 → 절전을 `안 함` 으로
- 중간에 끊겨도 **같은 명령을 다시 치면 이어서** 간다. 다시 받지 않는다.

## 결과 보기

끝나면 폴더 이름이 나온다. 예: `SUN-2026-08-09`.

```bash
explorer office/production/SUN-2026-08-09/renders
```

파일 탐색기가 열리고 MP4 3개가 있다. 더블클릭해서 본다.

```bash
notepad office/production/SUN-2026-08-09/publish-package.md
```

제목·훅·설명문·근거가 정리돼 있다. 유튜브에 올릴 때 그대로 쓰면 된다.

**자동 업로드는 없다.** 마음에 드는 편을 골라 직접 올린다.
`⚠️` 가 붙은 클립은 올리기 전에 확인한다 — 찬양이 깔렸거나 회중석 얼굴이
잡힌 경우다.

# 3부 · 고치기

폴더 이름(`SUN-2026-08-09`)은 본인 것으로 바꿔서 친다.

## 자막 글자가 틀렸을 때

**이게 제일 흔하다.** 음성 인식이 사람 이름이나 교회 이름을 잘못 듣는다.

### 한 단어가 계속 틀리는 경우

```bash
python scripts/sermon_shorts.py fix SUN-2026-08-09 혜성교회 예심교회 --remember
```

```bash
python scripts/sermon_shorts.py render SUN-2026-08-09
```

전사본과 자막에서 그 말을 **한 번에** 바꾼다. 어디를 고쳤는지 시각과 함께
보여준다.

`--remember` 를 붙이면 **앞으로 만드는 모든 편에 자동으로 적용된다.**
교회 이름처럼 매번 틀리는 말은 한 번만 등록하면 된다.

> 한글을 Git Bash에 붙여넣는 게 잘 안 되면, 메모장에 명령을 쓴 다음 복사해
> 붙여넣으면 된다.

### 문장을 직접 다듬고 싶은 경우

세 단계다. 1번은 한 번만, 2~3번은 고칠 때마다 반복한다.

```
captions  →  메모장  →  render
자막 꺼내기    글자 고치기      다시 굽기
```

**1 · 자막 파일 꺼내기**

```bash
python scripts/sermon_shorts.py captions SUN-2026-08-09
```

클립별 자막이 `captions/clip-01.srt` · `clip-02.srt` · `clip-03.srt` 로 생긴다.

**2 · srt 파일 열어서 고치기**

`.srt` 는 **글자만 든 파일**이다. 메모장 종류면 다 열린다.

- **쓴다** — 메모장. 컴퓨터에 기본으로 있다. VS Code 같은 편집기가 있으면 그것도 좋다
- **안 쓴다** — 워드 · 한글(HWP) · 엑셀. 열리기는 하지만 저장할 때 자기 형식으로
  바꿔 버려 파일이 망가진다

```bash
notepad office/production/SUN-2026-08-09/captions/clip-01.srt
```

파일은 이렇게 생겼다:

```
1
00:00:00,000 --> 00:00:03,400
근데 그 강사님이 생각을 해 보니까
```

**숫자와 `-->` 줄은 건드리지 않는다. 맨 아랫줄 글자만 고친다.**
시간을 바꾸면 자막이 말과 어긋난다. 실수로 망가뜨리면 렌더가 멈추고 이유를 말해 준다.

저장은 `Ctrl + S`. **메모장이 인코딩을 물으면 UTF-8 로 저장한다.**

한글이 옛날 방식(CP949)으로 저장돼도 이제는 알아서 읽는다. 그래도 글자가 깨진
파일이면 **렌더를 거부하고** 무엇을 고치라고 알려준다 — 깨진 자막이 구워진 영상이
나오는 것보다 낫다.

**3 · 다시 렌더**

```bash
python scripts/sermon_shorts.py render SUN-2026-08-09
```

`captions/` 에 파일이 있으면 렌더가 **그것을 쓴다.** 전사본은 쳐다보지도 않는다.
다시 전사해도, 구간을 다시 골라도 고친 자막은 그대로 남는다.

한 편만 다시 만들려면 — 3편 전부 다시 구울 필요가 없다:

```bash
python scripts/sermon_shorts.py render SUN-2026-08-09 --only clip-02
```

다운로드와 전사는 건너뛰고 굽기만 하므로 **클립 하나에 1~3분**이다.

고치기 전으로 되돌리고 싶으면 그 srt를 지우고 `captions` 를 다시 돌린다.

## 구간이 마음에 안 들 때

`clips.json` 의 `start` / `end` 초만 고치고 렌더만 다시 한다:

```bash
notepad office/production/SUN-2026-08-09/clips.json
```

```bash
python scripts/sermon_shorts.py render SUN-2026-08-09
```

다른 구간으로 아예 다시 골라달라고 하려면:

```bash
python scripts/sermon_shorts.py select SUN-2026-08-09 --count 3
```

```bash
python scripts/sermon_shorts.py render SUN-2026-08-09
```

## 설교 구간을 잘못 잡았을 때

찬양이나 광고가 클립에 들어갔다면 설교 시작·끝 시각을 직접 준다.
전사부터 다시 하므로 시간이 걸린다:

```bash
rm office/production/SUN-2026-08-09/transcript.json
```

```bash
python scripts/sermon_shorts.py transcribe SUN-2026-08-09 --sermon-window 0:45:00 1:20:00
```

## 엔드카드 — 자동으로 붙는다

**따로 할 일이 없다.** 본편이 끝나면 4초짜리 카드가 저절로 붙는다.

```
        2024년 6월 23일 주일예배      ← 언제 드린 예배인지
           신명기 12:1-8            ← 설교 본문
     택하신 곳으로 나아가야 하는 이유    ← 설교 제목
         설교 · 장선기 목사           ← 설교자
          방배동 예심교회             ← 교회명
       youtube.com/@yeshim1126
```

유튜브 영상 제목에 다섯 가지가 전부 들어 있어서 거기서 뽑는다. 쇼츠는 채널을
떠나 혼자 돌아다니기 때문에, 이걸 보고 유튜브에 검색하면 원래 설교 영상이 나온다.

- 본문은 **풀어서** 쓴다 — `삼하` → `사무엘하`. 줄임말로는 검색이 안 된다
- 날짜는 제목이 아니라 **폴더 이름**에서 가져온다. 채널 제목의 날짜가 틀린 적이
  있어서다 (2026-07-14는 화요일, 실제로는 07-12 주일예배였다)

### 내용을 고치고 싶으면

```bash
notepad office/production/SUN-2026-08-09/end-card.json
```

```bash
python scripts/sermon_shorts.py render SUN-2026-08-09
```

파일이 이미 있으면 다시 만들지 않으므로 고친 내용이 유지된다.

### 카드를 빼고 싶으면

```bash
python scripts/sermon_shorts.py render SUN-2026-08-09 --no-end-card
```

# 막힐 때

| 화면에 나온 것 | 뜻 | 할 것 |
|---|---|---|
| `python: command not found` | PATH 체크 안 함 | Python 재설치, `Add python.exe to PATH` 체크 |
| `bash: git: command not found` | Git 미설치 | 1부 1번 |
| `npm: command not found` | Node 미설치 / 창 안 닫음 | Node 설치 후 Git Bash 새로 열기 |
| `no such file or directory` | 폴더가 아님 | `cd ~/shorts-factory` |
| `URL이 아니다: '#'` | 설명까지 복사됨 | 회색 상자 안만 복사 |
| `인자를 받지 않는다` | 위와 같음 | 명령만 친다 |
| `전사할 수단이 없다` | whisper 미설치 | 1부 5번 |
| `GEMINI_API_KEY not set` | 옛날 코드 | `git pull` |
| 자막이 네모(□□□)로 나옴 | 폰트 문제 | `assets/fonts` 에 ttf 2개가 있는지 확인 |
| 30분간 아무것도 안 나옴 | 전사 중 | 정상. 기다린다 |
| `No space left` | 디스크 부족 | 오래된 `renders/` 지우기 |

그래도 안 되면 **Git Bash 글자를 그대로 복사해서** Claude에게 붙여넣는다.

## 윈도우에서만 나오는 것들

- **경로에 한글이 있으면 문제가 생길 수 있다.** 윈도우 사용자 이름이 한글이면
  `C:\shorts-factory` 처럼 영문 경로에 clone 하는 편이 안전하다:
  ```bash
  cd /c/
  ```
