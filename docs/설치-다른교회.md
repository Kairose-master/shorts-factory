# 우리 교회 설교 쇼츠 만들기 — 모든 교회용

유튜브에 올려 둔 설교에서 세로 쇼츠를 자동으로 뽑는 프로그램이다. 교회 채널
주소와 설교자 이름, 교회명만 넣으면 그 교회 것으로 돈다. **전부 무료고 API 키가
필요 없다.**

- 맥 또는 윈도우 · 여유 공간 20GB · 인터넷
- 비용 0원

## 무엇을 해 주는가 — 설교 한 편 → 쇼츠 3편

유튜브 예배 영상을 받아, 한국어로 받아쓰고, 쇼츠로 쓸 구간 세 개를 **전사본을
읽고** 고른 뒤, 세로로 잘라 자막을 입혀 MP4로 내놓는다. 사람이 하는 일은
마지막에 **골라서 올리는 것**뿐이다.

- 9:16 세로 · 1080×1920 · **1.5배속**
- 한국어 자막 **번인** — 유튜브 UI와 안 겹치게 배치
- 끝에 **엔드카드 4초** — 날짜 · 본문 · 제목 · 설교자 · 교회명
- 주일예배 실황에서는 **설교 구간 안에서만** 자른다. 찬양·기도·광고는 제외 —
  Content ID를 피하기 위해서다
- 새벽기도처럼 **정지 이미지에 음성만** 올린 영상도 된다. 이미지를 잘라내지 않고
  9:16에 맞춘다
- **업로드는 절대 자동으로 하지 않는다.** 렌더까지가 끝이다
- **설교자 음성을 합성하지 않는다.** 실제 하신 말씀만 자른다

# 1부 · 설치 (딱 한 번, 40~60분)

여기만 운영체제에 따라 갈린다. 본인 것만 하면 된다.
화면별 자세한 안내는 `docs/설치-맥.md` · `docs/설치-윈도우.md`.

**맥**

1. `command`+`스페이스` → **터미널** 실행
2. `xcode-select --install`
3. Homebrew 설치 — <https://brew.sh>
4. `brew install node`

**윈도우**

1. <https://git-scm.com/download/win> 설치 → **Git Bash** 실행
2. <https://www.python.org/downloads/windows/> 설치 —
   **`Add python.exe to PATH` 반드시 체크**
3. <https://nodejs.org> LTS 설치
4. Git Bash를 닫고 새로 연다

**여기서부터는 맥·윈도우가 완전히 같다.** 명령이 하나의 형태
(`bash scripts/shorts …`)로 통일돼 있어서다.

```bash
npm install -g @anthropic-ai/claude-code
```

```bash
claude
```

브라우저가 열리면 Claude 계정으로 로그인하고 `/exit` 로 나온다.
Claude 구독이 있으면 추가 비용이 없다 — 쇼츠 구간을 고르는 데만 쓴다.

```bash
cd ~
```

```bash
git clone -b claude/shorts-creation-automation-0xaii8 https://github.com/Kairose-master/shorts-factory
```

```bash
cd ~/shorts-factory
```

```bash
bash scripts/setup_render_env.sh --with-whisper
```

20~40분 걸린다. 끝나면 `export` 로 시작하는 두 줄이 나온다. 맥은 `~/.zshrc`,
윈도우는 `~/.bashrc` 에 넣고 **터미널을 닫았다 새로 연다.**

# 2부 · 우리 교회로 맞추기 (딱 한 번, 1분)

세 가지만 넣으면 된다.

| | 무엇 |
|---|---|
| **채널 주소** | 유튜브에서 교회 채널에 들어가 주소창의 `@` 로 시작하는 주소 |
| **설교자** | 영상 **제목에 적히는 이름 그대로**. "홍길동 목사"면 `홍길동` 만 |
| **교회명** | 엔드카드에 찍힐 이름 |

```bash
bash scripts/shorts config --channel https://www.youtube.com/@내채널 --preacher 홍길동 --church "서울○○교회"
```

제대로 잡혔는지 본다:

```bash
bash scripts/shorts sermons
```

```
https://www.youtube.com/@내채널  ·  홍길동 새벽기도 757편 · 수요예배 30편 · 주일예배 185편

  2026-08-30  주일예배  69분  l3LbSLU39jU  2026-08-30 [삼하 22:1-8] …
  2026-08-28  새벽기도  43분  Y1ABPz8B7kw  2026-8-28[겔47:13-23]/새벽기도/…
```

> **아무것도 안 나오면 설교자 이름이 제목과 다르다.** 제목에 이름이 아예 없는
> 채널이면 `--preacher ""` 로 비워 두고 모든 영상을 대상으로 할 수 있다. 다만
> 그러면 어린이부·행사 영상까지 섞이니 결과를 꼭 확인한다.

> **영상 제목에 날짜와 성경 본문이 있으면 훨씬 좋다.**
> `2026-08-30 [삼하 22:1-8] 제목 / 홍길동 목사` 처럼. 날짜로 폴더 이름을,
> 본문과 제목으로 엔드카드를 자동으로 채운다. 없어도 돌아가지만 엔드카드를
> 손으로 채워야 한다.

확인:

```bash
bash scripts/shorts doctor
```

```bash
bash scripts/smoke_test_render.sh
```

`PASS` 가 나오면 준비 끝이다.

# 3부 · 만들기

**플랜 A — 알아서 골라줘.** 아직 안 만든 설교를 무작위로 하나 뽑아 끝까지 간다.
주일예배·수요예배·새벽기도가 골고루 뽑히도록 종류를 먼저 고른다.

```bash
bash scripts/shorts-auto.sh
```

**플랜 B — 이 설교로 해줘.** 주소를 큰따옴표로 감싼다.

```bash
bash scripts/shorts-url.sh "https://www.youtube.com/watch?v=..."
```

## 얼마나 걸리나

```
1/4 내려받기    5~15분
2/4 한국어 전사  20~60분   ← 제일 오래 걸린다
3/4 구간 선별    2~5분
4/4 렌더        3~15분
```

- 터미널 창을 **닫으면 중단된다.** 그대로 둔다
- 컴퓨터가 잠들면 멈춘다. 절전을 꺼 두거나 가끔 마우스를 움직인다
- 중간에 끊겨도 **같은 명령을 다시 치면 이어서** 간다

## 결과

```
office/production/SUN-2026-08-30/
├── renders/            MP4 3편
├── publish-package.md  제목 · 훅 · 설명문 · 선정 근거
├── captions/           자막 (고칠 수 있음)
└── clips.json          구간과 근거
```

`publish-package.md` 의 제목과 설명문을 그대로 복사해 올리면 된다.
`⚠️` 가 붙은 클립은 올리기 전에 확인한다.

# 4부 · 고치기

## 자막 글자가 틀렸을 때

**한 단어가 계속 틀린다:**

```bash
bash scripts/shorts fix SUN-2026-08-30 혜성교회 예심교회 --remember
```

```bash
bash scripts/shorts render SUN-2026-08-30
```

`--remember` 를 붙이면 앞으로 만드는 모든 편에 자동 적용된다.

**문장을 직접 다듬는다:**

```bash
bash scripts/shorts captions SUN-2026-08-30
```

**이 명령을 돌려야 `captions/` 폴더가 만들어진다** — 그 전에는 `renders` 와
`source` 폴더만 있다.

> **`renders/subs/` 안의 srt 는 고쳐도 소용없다.** 그쪽은 렌더할 때마다 새로
> 만들어지는 결과물이다. 고칠 곳은 `captions/` 다.

메모장·텍스트편집기로 열어 **맨 아랫줄 글자만** 고친다. 시간 줄은 그대로 둔다.
워드·한글(HWP)은 파일을 망가뜨리니 쓰지 않는다.
**반드시 저장한다** (`command`/`Ctrl` + `S`).

```bash
bash scripts/shorts captions SUN-2026-08-30 --show
```

지금 파일에 뭐라고 적혀 있는지 디스크에서 그대로 읽어 준다. 저장이 됐는지,
렌더를 돌렸는지까지 알려준다.

```bash
bash scripts/shorts render SUN-2026-08-30 --only clip-01
```

`--only` 로 한 편만 다시 구우면 1~3분이면 끝난다.

## 그 밖에

| 고치고 싶은 것 | 방법 |
|---|---|
| 구간의 초를 조정 | `clips.json` 의 start / end 를 고치고 render |
| 다른 구간으로 다시 | `shorts select <id> --count 3` → render |
| 설교 구간을 잘못 잡음 | `transcript.json` 지우고 `transcribe <id> --sermon-window 0:45:00 1:20:00` |
| 엔드카드 내용 | `end-card.json` 을 고치고 render |
| 엔드카드 빼기 | `render <id> --no-end-card` |
| 제목 크기 | `TITLE_SIZE=110` 을 앞에 붙여 render (기본 92) |
| 공간 정리 | 다 만든 편의 `source/` 폴더를 지운다 |

# 막힐 때

| 화면에 나온 것 | 뜻 | 할 것 |
|---|---|---|
| `command not found: python` | 맥은 python3 다 | `bash scripts/shorts …` 형태로 친다 |
| `python: command not found` | 윈도우 PATH 체크 안 함 | Python 재설치, `Add python.exe to PATH` |
| `URL이 아니다: '#'` | 설명까지 복사됨 | 회색 상자 안만 복사 |
| `전사할 수단이 없다` | whisper 미설치 | `setup_render_env.sh --with-whisper` |
| `아무것도 못 찾았다` | 설교자 이름이 제목과 다름 | `shorts sermons` 확인 후 `config` 다시 |
| `자막을 고쳤는데 그대로` | 저장 안 됨 / 다른 폴더 | `captions … --show` 로 확인 |
| 20분간 아무것도 안 나옴 | 전사 중 | 정상. 기다린다 |

그래도 안 되면 **터미널 글자를 그대로 복사해서** Claude에게 붙여넣는다.

# 교회에서 쓰기 전에 — 지켜야 할 선

- **업로드는 사람이 한다.** 어느 단계에도 자동 업로드가 없다
- **찬양 구간은 피한다.** CCLI는 예배 사용 범위이지 유튜브 배포 범위가 아니다.
  찬양이 깔린 구간에는 경고가 붙는다
- **회중석이 잡힌 화면은 확인한다.** 성도 얼굴이 나오면 크롭하거나 버린다
- **설교자 음성을 합성하지 않는다.** 실제 하신 말씀만 자른다
- 설교 구간 밖은 잘려 나가고, 15초 미만은 버려지며, 왜 그 구간인지 근거가 없으면
  렌더가 거부된다 — 저작권 방어선은 모델의 판단이 아니라 파이프라인 구조에 있다
